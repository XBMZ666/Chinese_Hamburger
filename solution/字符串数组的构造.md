# 字符串数组的构造
现在想构造一个数组, 让数组装有不同的字符串, 可以选取以下两种数组.
* 字符型指针数组：`char * arr[]`, 该数组中的每个元素形式上是常量字符串, 实际上是常量字符串的指针.
* 二维字符数组：`char arr[][]`, 该数组的行决定了有多少个字符串, 该数组的列决定了每个字符串的长度（列数将`'\0'`计入, 因此列数 - 1为字符串的最大长度）.

---

## 字符型指针数组：`char * arr[]`
```c
#include <stdio.h>

int main()
{
    char * strs[3] = {"Apple", "Banana", "Cherry"};

    for (int i = 0; i < 3; i++)
    {
        printf("%s\n", strs[i]);
    }

    return 0;
}
```
---

## 二维字符数组：`char arr[][]`
```c
#include <stdio.h>

int main()
{
    char strs[3][7] = {"Apple", "Banana", "Cherry"};

    for (int i = 0; i < 3; i++)
    {
        printf("%s\n", strs[i]);
    }
    
    return 0;
}
```

## 字符串常量（字符串字面量）
在C语言中, 由双引号`""`括起来的, 比如`"Apple"`, 被称作字符串常量.\
编译器在编译时, 字符串常量会被放置到内存的**只读数据段**, 这块内存空间被操作系统锁死, 只读而不能修改.\
因此, 若写下`char * p = "Apple";`, 则`p`是一个指向常量字符串的指针, 要是想通过操作`p`来直接操作常量字符串所在的内存空间, 则会出现段错误！
* 对于字符型指针数组, 数组中的每个元素都是字符串常量的指针, 那么结合上面的分析：现在只能通过遍历数组元素（字符串常量的指针）来访问这些常量字符串, 而不能通过操作数组元素（字符串常量的指针）来具体地更改常量字符串中的某个或某些字符.
* 对于二维字符数组, 在初始化时, 会发生拷贝, 即：由双引号`""`括起来的字符串常量, 会被逐字符地（包括`'\0'`）拷贝到创建数组所申请的连续内存空间中.\
该过程中, 编译器先在只读区找到字符串常量, 然后在栈区分配了创建数组所需的连续内存空间, 再把只读区中字符串常量的字符（包括`'\0'`）逐个拷贝到数组的连续内存空间中.（如果数组是全局变量, 那么把栈区替换为全局内存区）\
拷贝完成后, 我们就可以借助数组下标来操作“字符串常量在栈区的拷贝”, 从而实现具体地更改常量字符串（实际上是字符串在栈区的副本）中的某个或某些字符.
* AI举例时间：字符串常量的`"Apple"`就像博物馆的名画（在只读区）, 可望而不可即；`char * p = "Apple"`就像是拿了个相机拍下画的位置, 也只能在原地看, 同样是可望而不可即；`char arr[3][20] = {"Apple"}`就像是买了一副名画的高仿的复印件, 想在上面乱涂乱画就乱涂乱画.
