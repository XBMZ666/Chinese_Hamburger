## 0.拼命的企鹅
>一只企鹅在爬山, 每隔一段路都会遇到一块石头. 第一块石头的重量是a, 每往上走一段路, 石头重量就会变成上一段的平方. 企鹅可以选择把某些石头捡起来, 最后把捡到的石头重量相乘.
> 它怎样捡石头, 才能得到重量乘积恰好是a的b次方的石头？（比如b = 173时, 要捡哪些石头？）
### (1).核心知识
* 幂的运算规则：同底数幂相乘, 底数不变, 指数相加. 即a^m^ × a^n^ = a^m+n^.
* ==n进制==向==10进制==的转换：对于某个n进制数, 若其从低位到高位共x个有效数位, 那么从最低位（第1位）到最高位（第x位）, 数位的权重分别为n^0^、n^1^、n^2^、n^3^、n^4^……n^x-3^、n^x-2^、n^x-1^. 当将此数转换为10进制时, 即先让各数位上的数乘其权重, 再将所有数乘权重的结果相加, 相加所得即为原数的10进制表示.
*  二进制的==唯一==性：任何非负整数都可以==唯一==地写成互不相同的2的幂之和.
* 除二取余法：需要把10进制数转换为2进制表示, 可以让该10进制==不断除以2==, 每次记录下余数. 最终先写最后一个余数, 再依次写之前的余数, 就得到了原数的2进制表示.


### (2).题目解析
根据题意，先写出石头的重量序列：==$a^{2^0}$, $a^{2^1}$, $a^{2^2}$, $a^{2^3}$, $a^{2^4}$, $a^{2^5}$……==   

这个问题可以先简化为：现在给定一个整数b, 要从重量序列中, 选取若干个重量相乘, 使这些重量的乘积恰好为$a^b$.

由于同底数幂相乘时, 底数不变, 指数相加, 那么若干个重量相乘时, 结果的底数仍为a, 在指数位置即若干个底数为2的幂的和, 此时则有：若干个底数为2的幂的和为b.
那么问题便可以进一步简化：给定一个整数b, 现在要找出若干个底数为2的幂, 使它们之和恰好为b.

不难想到把b转换为二进制形式：转换为二进制后, 根据每一数位是0或者1, 可以直观地将b展开为若干个底数为2的幂的和. 

当b = 173时, 用除二取余法, 将b转换为二进制形式：
==173 ÷ 2 = 86== 余1
==86 ÷ 2 = 43== 余0
==43 ÷ 2 = 21== 余1
==21 ÷ 2 = 10== 余1
==10 ÷ 2 = 5== 余0
==5 ÷ 2 = 2== 余1
==2 ÷ 2 = 1== 余0
==1 ÷ 2 = 0== 余1
从后往前排列余数（这里注意排列顺序不要搞反）, 可以得到十进制数173的二进制表示为：==10101101==.
由此可得：==173 = 2^0^ + 2^2^ + 2^3^ + 2^5^ + 2^7^==.
又因为$2^i$实际上对应第==i + 1==块石头的重量,
所以应该选取第==1==块石头、第==3==块石头、第==4==块石头、第==6==块石头、第==8==块石头.

 
### (3).题目答案
* 问题回答
>Q：它怎样捡石头, 才能得到重量乘积恰好是a的b次方的石头？
>A：捡第==1==块石头、第==3==块石头、第==4==块石头、第==6==块石头、第==8==块石头.

## 1.西邮Linux欢迎你啊
>请解释以下代码的运行结果.
>	```c
>int main() {
>      if (printf("Hi guys! ") || printf("Xiyou Linux ")) {
>         printf("%d\n", printf("Welcome to Xiyou Linux 2%d", printf("")));
>      }
>}
>```

### (1).核心知识
* 逻辑或运算符`||`：计算表达式`A||B`时, 会先执行表达式`A`, 并判断`A`的值是“真”还是“假”——若为“真”, 则表达式`A||B`的值为“真”, 不会进一步执行表达式`B`；若为“假”, 则进一步执行表达式`B`. 若表达式`B`的值为“真”, 则表达式`A||B`的值为“真”. 若表达式`B`的值为“假”, 则表达式`A||B`的值为“假”.
上面的表述通常被概括为逻辑或运算符`||`的“短路性质”, 通俗地讲, 表达式`A||B`一真则真, 全假才假. 逻辑与运算符`&&`也具有该性质, 表达式`A&&B`一假则假, 全真才真.
* `printf`函数的返回值：调用后成功打印输出的字符总数. 当打印输出发生错误时, 则会返回一个负值.
* 链式访问：若函数`functionA`调用后的返回值作为另一个函数`functionB`的参数, 则前者被视为内层函数, 后者被视为外层函数. 内层函数先执行, 接着其返回值再作为外层函数的参数.
### (2).题目解析
首先判断`if`语句的条件, 其条件为一个用逻辑或运算符`||`连接的表达式：从左向右看, 先执行`printf("Hi guys! ")`,打印输出：`"Hi guys! "`, 由于成功打印输出了`'H'`,`'i'`,`' '`,`'g'`,`'u'`,`'y'`,`'s'`,`'!'`,`' '`共9个字符, 那么这个`printf`函数的返回值是9.

根据逻辑或运算符`||`的短路性质：现在左值已经为“真”, 那么对于用逻辑或运算符`||`连接的整个表达式为“真”, 就不再计算右边表达式的值, 故不会执行`printf("Xiyou Linux ")`.

现在`if`语句条件为“真”, 则进入其内部：出现链式访问, 那么会从最内层的`printf`函数开始执行.

先执行`printf("")`,什么都没有打印输出出来, 那么该`printf`函数的返回值为0.

接下来执行`printf("Welcome to Xiyou Linux 2%d", 0)`, 打印输出：`"Welcome to Xiyou Linux 20"`, 成功打印输出了25个字符, 那么该`printf`函数的返回值是25.

最后执行`printf("%d\n", 25)`, 打印输出`"25\n"`.


### (3).题目答案
* 输出结果
**Hi guys! Welcome to Xiyou Linux 2025**

## 2.可以和\0组一辈子字符串吗？
>你能找到成功打印的语句吗？你能看出每个`if`中函数的返回值吗？这些函数各有什么特点？
>```c
>int main() {
>    char p1[] = { 'W', 'e', 'l', 'c', 'o', 'm', 'e', '\0' };
>    char p2[] = "Join us\0", p4[] = "xiyou_linux_group";
>    const char* p3 = "Xiyou Linux Group\0\n2025\0";
>    if (strcmp(p1, p2)) {
>      printf("%s to %s!\n", p1, p2);
>    }
>    if (strlen(p3) > sizeof(p3)) {
>      printf("%s", p3);
>    }
>    if (sizeof(p1) == sizeof(p2)) {
>      printf("%s", p4);
>    }
>}
>```
### (1).核心知识
* 编译器在字符串的末尾会自动添加一个隐式的字符`'\0'`.
* 转义字符`'\0'`：具有截断作用, 即在字符串字面量中, 会被解析为字符串的结束符, 因此无论后面是否有其他字符, 在使用字符串处理函数时, 遇到`'\0'`总会立即停止解析.
* `strcmp`函数：用于比较两个字符串, 从两个字符串的首字符开始, 逐一比较各字符的ASCII码值, 直到遇到不同的字符或遇到`'\0'`为止. 例如`strcmp(str1, str2)`, `str1`和`str2`分别表示字符串X、Y（字符串通常由字符数组表示, 故字符串名通常为数组名）, 这里由于传参给函数, 所以退化为字符串X、Y的指针. 若没有比较出不同, 则`strcmp`函数返回0；若比较出不同, 当结果为X较大时, `strcmp`函数返回正值, 而当结果为X较小时, `strcmp`函数返回负值.
* `sizeof`运算符：用于操作数据类型或变量, 计算其在内存中所占的大小.
* `strlen`函数：用于计算字符串的长度, 但不计入`'\0'`.
* 数组名的退化：数组名在参与运算、传参时会退化为指针，其指向为数组中首元素的地址.
* 指针变量的大小：即其所存储的地址的大小. 在64位系统下, 固定为==8==字节；在32位系统下, 固定为4字节.
### (2).题目解析
在初始化字符型数据的数组时, 一般有两种方式. 本题初始化字符型数组`p1`、`p2`、`p4`时, 采用了这两种方式, 那么就以这三个字符型数组的初始化为例来说明.
`p1`的初始化：使用`{}`来初始化. 这样初始化后, `{}`中的所有字符型元素即该数组的所有元素, “所见即所得”.
`p2`和`p4`的初始化：使用`""`来初始化, 即给字符型数组赋了一个为字符串的初值. 这样初始化的话, 由于编译器会自动在末尾追加一个隐式的`'\0'`, 因此在初始化后, 这个隐式的`'\0'`也会成为该数组的一个元素.

综上可得：
`p1`中的元素：`'W'`、`'e'`、`'l'`、`'c'`、`'o'`、`'m'`、`'e'`、`'\0'`. 共8个元素, 数组大小为8字节.
`p2`中的元素：`'J'`、`'o'`、`'i'`、`'n'`、`' '`、`'u'`、`'s'`、`'\0'`、`'\0'`. 共9个元素, 数组大小为9字节. 注意这里很坑的一点是, 在初始化`p2`时, `""`中有一个显式的`\0`, 但这==丝毫不影响==编译器自动在末尾再追加一个隐式的`'\0'`, 这样会使元素`'s'`后面紧跟着两个`'\0'`, 一个为显式的, 一个为隐式的.
`p4`中的元素：`'x'`、`'i'`、`'y'`、`'o'`、`'u'`、`'_'`、`'l'`、`'i'`、`'n'`、`'u'`、`'x'`、`'_'`、`'g'`、`'r'`、`'o'`、`'u'`、`'p'`、`'\0'`. 共18个元素, 数组大小为18字节.

`p3`是一个字符型指针, 接收了常量字符串的地址. 这个常量字符串在逻辑上被内部显式的`'\0'`截断, 但后面的`"\n2025\0"`仍然存在于内存中, 但被一个显式的`'\0'`和一个隐式的`'\0'`夹在之间.

对于`strcmp(p1, p2)`, 比较字符串`p1`和`p2`, 不难看出两个字符串的第一个字符就不相同, 而且`p1`的首字符为`'W'`, `p2`的首字符为`'J'`, `'W'`的ASCII码更大, 故认为`p1`这个字符串更大. 因此函数`strcmp(p1, p2)`返回一个正数, 为“真”.

对于`strlen(p3)`：从`p3`这个地址对应的字符开始逐一计数, 遇到`'\0'`停止且计数不包括`'\0'`, 共17个字符. 因此该函数的返回值为17.
对于`sizeof(p3)`：`p3`是一个指针, 则计算指针大小. 64位环境下指针大小为8字节, 故该表达式的值为8.

对于`sizeof(p1)`：`p1`是一个数组名, 则计算数组大小, 故该表达式的值为8.
对于`sizeof(p2)`：`p2`是一个数组名, 则计算数组大小, 故该表达式的值为9.
注意`sizeof`是运算符, 所以此处`()`中, 没有出现让数组名向函数传参, 也没有出现数组名参与运算, 那么不发生数组名退化.

注意在打印时, `printf`函数中的占位符`%s`对应的参数是一个字符型数据的地址, 此时打印原理就是从该地址所对应的数据开始, 依次打印之后的数据, 直至遇到`'\0'`结束.

### (3).题目答案
* 输出结果
**Welcome to Join us!**
**Xiyou Linux Group**

## 3.数学没问题，浮点数有鬼
>这个程序的输出是什么？解释为什么会这样？
>```c
>int main() {
>    float a1 = 0.3, b1 = 6e-1, sum1 = 0.9;
>    printf("a1 + b1 %s sum1\n", (a1 + b1 == sum1) ? "==" : "!=");
>    float a2 = 0x0.3p0, b2 = 0x6p-4, sum2 = 0x0.9p0;
>    printf("a2 + b2 %s sum2\n", (a2 + b2 == sum2) ? "==" : "!=");
>}
>```
### (1).核心知识
* 数据在内存中以二进制形式存放.
* 浮点数的二进制表示：对于浮点数, 很多十进制的==有限小数==转换成二进制后是==无限循环小数==.
* 浮点数的精度丢失（舍入误差）：由于浮点数类型的所占的内存空间有限, 故在把浮点数用二进制表示后, 无法存储无限循环下超出精度的部分, 因此会对这部分进行“四舍五入”（舍入到最近的偶数）, 这样会导致存储的浮点数只是真实值的==近似值==.
* 浮点数的比较：由于浮点数可能会精度丢失（注意也可能不丢失, 见题目解析）, 所以比较两个浮点数是否相等时, 不建议使用`==`.
* 浮点数的十六进制表示：格式为`0x`开头, `p`表示指数, 指数是以2为底的幂. 采用这种表示, 能精确地表示二进制小数, 从而避免十进制转换为二进制时的精度丢失.
* 条件表达式`条件 ? 表达式1 : 表达式2`：特指由三目运算符`? :`构成的表达式. 计算这个表达式的值时, 先判断条件为“真”还是“假”——若为“真”, 则以`表达式1`的值作为整个表达式的值；若为“假”, 则以`表达式2`的值作为整个表达式的值. 条件表达式可以被视为`if...else`语句的简化版.
### (2).题目解析
6e-1是科学计数法的写法, 意义为：6 × 10^-1^（0.6）.
先将0.3、0.6、0.9分别赋给`a1`、`b1`、`sum1`. 存储时会把所赋的值转换为二进制, 变为无限循环小数. 同时由于有限的精度, 所以发生截断, 实际存储的值会产生误差.
那么`a1 + b1`的值通常不等于`sum`的值, 故表达式`a1 + b1 == sum`通常为假.

==0x==是16进制的前缀. 当要将16进制数转换为2进制表示时, 可以将这个16进制数其每个数位上的数分别写成各自的2进制表示（不够4位就补前导0）, 最终所得即原16进制数的2进制表示.
例如, 现在有一个16进制数：==0x93==, ==9==的2进制表示是==1001==, ==3==的2进制表示是==0011==, 那么原16进制数的2进制表示：==10010011==.
有了以上前置知识, 我们来分析如果是浮点数的16进制表示, 其所对应的10进制表示是怎样的：
①==0x0.3p0==：
先将16进制下的==0.3==转换为2进制表示, 即==0.0011==. 
接着==p0==代表2进制表示的小数点不移位. 
那么16进制下的==0x0.3p0==转换为2进制表示：==0.0011==, 再转换为10进制表示：==2^-3^ + 2^-4^ = 0.1875==, 是一个精确的值.
②==0x6p-4==：
先将16进制下的==6==转换为2进制表示, 即==110==. 
接着==p-4==代表2进制表示的小数点需要左移4位, 得到==0.011==. 
那么16进制下的==0x6p-4==转换为2进制表示：==0.011==, 再转换为10进制表示：==2^-2^ + 2^-3^ = 0.375==, 是一个精确的值. 
③==0x0.9p0==：
先将16进制下的==0.9==转换为2进制表示, 即==0.1001==. 
接着==p0==代表2进制表示的小数点不移位. 
那么16进制下的==0x0.9p0==转换为2进制表示：==0.1001==, 再转换为10进制表示：==2^-1^ + 2^-4^ = 0.5625==, 是一个精确的值.

以上的转换思路可以加深我们对“不同进制相互转换”的理解, 不过并不能让我们快捷地来进制转换, 所以在这里再提供一种更简单的转换思路. 就以==0x6p-4==为例：对于16进制数, 从最低位向最高位数, 第==i==位的权重是==16^i-1^==, 所以把==6==直接转换为10进制表示：==6 × 16^0^ = 6==, 又因为==p-4==表示==2^-4^==, 那么原16进制数的10进制表示：==6 × 2^-4^ = 0.375==.

综上, `a2`, `b2`, `sum2`的值分别为0.1875, 0.375, 0.5625, 由于==0.1875 + 0.375 = 0.5625==, 则表达式`a2 + b2 == sum2`为“真”.





### (3).题目答案
* 输出结果
**a1 + b1 != sum1**
**a2 + b2 == sum2**

## 4.不合群的数字
>在一个数组中, 所有数字都出现了偶数次, 只有两个数字出现了奇数次, 请聪明的你帮我看看以下代码是如何找到这两个数字的呢？
>```c
>void findUndercoverIDs(int nums[], int size) {
>     int xorAll = 0, id_a = 0, id_b = 0;
>     for (int i = 0; i < size; i++) {
>        xorAll ^= nums[i];
>     }
>     int diffBit = xorAll & -xorAll;
>     for ( int i = 0; i < size; i++) {
>        if(nums[i] & diffBit) {
>           id_a ^= nums[i];
>        } else {
>           id_b ^= nums[i];
>        }
>     }
>     printf("These nums are %d %d\n", id_a, id_b);
>}
>```
### (1).核心知识
* 按位异或运算符`^`：二目操作符, 从两个操作对象的二进制位的最低位开始, 位相同得0, 位不同得1.
* 异或运算的性质：
①归零律：==a ^ a = 0==
②恒等律：==a ^ 0 = a==
③交换律：==a ^ b = b ^ a==
④结合律：==a ^ b ^ c = (a ^ b) ^ c = a ^ (b ^ c)==
* 位运算时对操作对象的==补码==进行运算. 正数的原码和补码相同；负数的补码是由原码==保持符号位（最高位）不变==, 取反再加一而得到的. 注意一个易错点：位运算时, ==符号位（最高位）也参与运算==, 而不是保持不变.
### (2).题目解析 + 题目答案
第一个`for`语句的循环体中, 初值为0的`xorAll`依次与数组`nums`中的所有元素进行异或运算, 每次异或运算后以结果来更新`xorAll`的值. 
那么这个`for`语句等价于：
`xorAll = xorAll ^ nums[0] ^ nums[1] ^ nums[2] ^ nums[3] ^ …… ^ nums[size-2] ^ nums[size-1];`

由题意：对于数组`nums`的元素`nums[i]`, 除了`A`和`B`, 其他元素`nums[k]`都会出现偶数次.
那么根据异或运算的交换律和结合律：先让相同的元素移动到一起, 再让出现偶数次的元素结合与自己相同的元素, 那么便有了若干组的结合. 再由异或运算的归零律：如果一个数异或它本身, 那么结果一定为0, 所以这时每组结合的结果就为0.
（比如nums[k~1~]在数组`nums`中出现了4次, 那么它所对应的一组结合：==nums[k~1~] ^ nums[k~1~] ^ nums[k~1~] ^ nums[k~1~] = 0==）

那么`xorAll`的值其实就是`A ^ B`的值. 由于`A`和`B`的值不相等, 所以`xorAll`的二进制表示中, 至少有一位是1.
现在即为已知`A ^ B`的值, 需要求出`A`和`B`各自的值.

对于`A ^ B`的值, 从最低位到最高位, 如果是0, 可说明`A`和`B`在该数位的数相同；如果是1, 那么说明`A`和`B`在该数位的数不同.
如果我们从最低位到最高位, 找出了`A`和`B`首次出现不同的数位, 那我们可以考虑把原数组中的数字分成两类, 分类依据是在这个数位上的值, 一类在这个数位上的值为0, 一类在这个数位上的值为1. 分类结束后, 对每一类的数, 继续与一个初值为0的变量（比如题中所给的`id_a`和`id_b`）依次异或, 每次异或完用结果更新这个变量的值. 由于抵消, 所以变量最终的值即为`0 ^ A`或`0 ^ B`的值, 由恒等律：==0 ^ A = A==且==0 ^ B = B==, 那么变量最终的值其实就是`A`和`B`的值.

要想找到最先为1的数位, 采取`xorAll & -xorAll.`
正数的原码与补码相同, 所以我们写出正数的原码（这个数的二进制表示）也就是其补码. 而负数的补码是在原码的符号位保持不变时, 对原码取反再加一才得到的. 

以某个正数`x`为例.
①写出正数`x`的原码和补码：
……10==1==000000.
②`-x`与`x`的原码, 除了符号位不同外, 其余位相同：
……10==1==000000.
③写出`-x`的补码：
先对`-x`的原码取反：
……01==0==111111, 
随后加一：
……01==1==000000

那么可见`x & -x`的结果：……00==1==000000（只有一位为1）. 因为`x`的补码最高位是0, `-x`的补码最高位是1, 所以`x & -x`的最高位是0, 所得数是一个正数, 原码与补码相同, 二进制表示为：……00==1==000000（只有一位为1）.
这样我们就找到了`x`的最先为1的数位.

## 5.会一直循环吗？

* `char* argv[]`：每个命令行参数被视作一个字符串, 所有字符串共同构成一个字符串数组, 这里的`argv`就是字符串数组的指针.

## 6.const与指针：谁能动, 谁不能动？
>```c
>struct P {
>     int x;
>     const int y;
>};
>int main() {
>    struct P p1 = { 10, 20 }, p2 = { 30, 40 };
>    const struct P p3 = { 50, 60 };
>    struct P* const ptr1 = &p1;
>    const struct P* ptr2 = &p2;
>    const struct P* const ptr3 = &p3; 
>```
>说说下列操作是否合法, 并解释原因.
>`ptr1->x = 100` ； `ptr2->x = 300` ； `ptr3->x = 500` ；
>`ptr1->y = 200` ； `ptr2->y = 400` ； `ptr3->y = 600` ；
>`ptr1 = &p2` ； `ptr2 = &p1` ； `ptr3 = &p1` ；
### (1).核心知识
* `const`关键字：让其所修饰的变量在初始化后的值不能再被更改. 当使用`const`关键字修饰指针时：`const`在`*`左边则修饰指针所指向的内容, 使指针成为“常量指针”；`const`在`*`右边则修饰指针的指向, 使指针成为“指针常量”.
### (2).题目解析
在主函数外, 定义了一个结构体类型`struct P`, 成员元素包括`int x`和`const int y`.

在主函数内, 定义了3个类型为`struct P`的结构体`p1`、`p2`、`p3`, 还定义了三个指针`ptr1`、`ptr2`、`ptr3`. `ptr1`、`ptr2`、`ptr3`分别指向`p1`、`p2`、`p3`.

我们只要明确什么不可变后, 剩下的都是可变的：
①在类型为`struct P`的结构体中, 成员`int y`由关键字`const`修饰后, 不可变.
所以以下操作不合法：`ptr1->y = 200` ； `ptr2->y = 400` ； `ptr3->y = 600`；

②结构体`p3`不可变, 也就是说其成员`int x`和`int y`都不可变.
所以以下操作不合法：`ptr3->x = 500` ； `ptr3->y = 600`；

③指针`ptr1`的指向不可变, 也就是说`ptr1`存放了`p1`的地址后, 不能再换而存放其他结构体的地址.
所以以下操作不合法：`ptr1 = &p2`；

④指针`ptr2`所指向的内容不可变, 即结构体`p2`不可变, 也就是说其成员`int x`和`int y`都不可变.
所以以下操作不合法：`ptr2->x = 300` ； `ptr2->y = 400`；

⑤指针`ptr3`的指向不可变, 也就是说`ptr3`存放了`p3`的地址后, 不能再换而存放其他结构体的地址. 同时, 指针`ptr3`所指向的内容也不可变, 即结构体`p3`不可变, 也就是说其成员`int x`和`int y`都不可变.
所以以下操作不合法：`ptr3->x = 500` ； `ptr3->y = 600` ； `ptr3 = &p1`；

剩下的操作都是合法的：`ptr1->x = 100` ； `ptr2 = &p1` ； 

### (3).题目答案
* 问题回答
>Q：说说下列操作是否合法.
>A：仅`ptr1-> x =100`和`ptr2 = &p1`合法, 其他操作都不合法.

## 7.指针！数组！
>在主函数中定义如下变量：
>```c
>int main() {
>    int a[3] = { 2, 4, 8 };
>    int(*b)[3] = &a;
>    int* c[3] = { a, a + 1, a + 2 };
>    int (*f1(int))(int*, int);
>}
>```
>说说这几个表达式的输出分别是什么？
>`a`, `*b`, `*b + 1`, `b`, `b + 1`, `* (*b + 1)`, `c`, `sizeof(a)`, `sizeof(b)`, `sizeof(&a)`, `sizeof(f1)`
### (1).核心知识
* 数组名的退化：数组名在参与运算、传参时会退化为指针, 其指向为数组中首元素的地址.
* `sizeof`运算符：用于操作数据类型或变量, 计算其在内存中所占的大小.
* 指针变量的大小：即其所存储的地址的大小. 在64位系统下, 固定为==8==字节；在32位系统下, 固定为4字节.
### (2).题目解析 + 题目答案
轻松读懂这段代码的关键是：能够清晰地区分指针数组（可以存储指针的数组）和数组指针（指向某个数组的指针）.
定义`a`是一个数组, 装有3个整型数据, 初始化使`a`中的元素为`2`, `4`, `8`.
定义`b`是一个指针, 指向一个装有3个整型数据的数组, 初始化使`b`存储数组`a`的地址.
定义`c`是一个数组, 装有3个整型指针, 初始化使`c`存储了3个数组名`a`, `a + 1`, `a + 2`, 这里发生了数组名退化, 三者依次表示指向数组`a`首元素的指针、指向数组`a`第二个元素的指针, 指向数组`a`第三个元素的指针.

现在分析语句`int (*f1(int))(int*, int);`：先找到标识符`f1`, 向右看, 紧挨着`(int)`, 这说明`f1`是一个函数, 拥有一个整型形参. 明确`f1`是函数后, 之后的分析就变得简单了.  `f1`左边紧挨的`*`说明`f1`的返回值是一个指针, 再向左看看到了`int`, 向右看到了`(int*, int)`, 进一步说明`f1`的返回值是一个指向函数的指针, 这个指针指向的函数的形参为`int*`和`int`, 且返回值为`int`.
那么这个语句到底在干什么呢？不难发现, 这里只出现了函数`f1`的函数头, 但是没有出现函数体, 那这个语句就是“函数的声明”, 其意义是：C语言在编译时会从上到下逐行扫描, 如果某个函数写在了主函数`main`之后, 那么会编译错误. 这个时候为了纠错, 便需要在主函数`main`之前对这个写在后面的函数进行声明, 写法便是写一个只剩函数名的语句.  

现在分析题目所给表达式.
`a`：数组名, 由于作为函数`printf`的参数, 所以会退化为指向数组`a`首元素的指针, 实质为一个地址.
`*b`：解引用指针`b`后, 得到数组`a`, 其实就是数组`a`的数组名, 这里也会退化成指向数组`a`首元素的指针, 实质为一个地址.
`*b + 1`：由上可知, 这里等价于`a + 1`, 为指向数组`a`第2个元素的指针, 实质还是一个地址.
`b`：指针, 实质为一个地址.
`b + 1`：相比于指针`b`, 跨过了整个数组`a`并指向了当前位置, 实质为一个地址.
`* (*b + 1)`：由上可知, `*b + 1`是指向数组`a`第2个元素的指针, 那么解引用`*b + 1`后, 得到数组`a`中第2个元素`a[1]`.
`c`：数组名, 退化为指向数组`c`首元素的指针, 实质为一个地址. 数组`c`存储了3个指针, 在64位环境下, 指针大小为8字节, 则数组大小为24字节.
`sizeof(a)`：计算数组`a`的大小, 为12字节.
`sizeof(b)`：计算指针`b`的大小, 为8字节.
`sizeof(&a)`：计算数组`a`的地址的大小, 为8字节.
`sizeof(f1)`：C语言规定函数不是对象, 没有大小, 所以`sizeof(函数名)`会导致编译错误.

## 8.全局还是局部！！！
>观察程序输出, 思考为什么？
>```c
>int g;
>int func() {
>    static int j = 98;
>    j += g;
>    return j;
>}
>int main() {
>    g += 3;
>    char arr[6] = {};
>    arr[1] = func();
>    arr[0] = func();
>    arr[2] = arr[3] = func() + 1;
>    arr[4] = func() + 1;
>    printf("%s linux\n", arr);
>    return 0;
>}
>```
### (1).核心知识
* 变量的**生命周期**：变量从创建到销毁之间的阶段.
* 变量的**作用域**：变量能够被直接使用的范围.
* 全局变量和局部变量

 变量类别|作用域|生命周期
:-:|:-:|:-:
全局变量|整个源文件|主函数`main`运行前创建, 整个程序退出时才销毁
局部变量|在定义它的函数内部|在函数调用时创建, 函数调用结束后销毁
`static`局部变量|在定义它的函数内部|在函数调用时创建, 整个程序退出时才销毁
* `static`关键字：修饰局部变量时, `static`局部变量无论函数调用多少次, 只初始化一次；同时`static`局部变量的生命周期延长, 每次函数调用时可以保留上次调用的终值；但`static`局部变量的作用域不变, 意味着在定义其的函数之外, `static`局部变量无法被直接使用.
* 字符型数据在内存中的存储, 实质是将其对应的ASCII码值存储到内存中, 因此字符型数据的实质为整型数据.
### (2).题目解析
首先, 在主函数外定义了一个全局变量`g`, 默认初值为0.

进入主函数后：
先执行`g += 3`, `g`的值变为3.
然后定义了一个大小为6的字符型数组`arr`, 默认里面的元素全为`'\0'`.

接下来：
首先, 执行`func()`：定义并初始化一个`static`局部变量`j`, 其值为98. 然后执行`j += g`, `j`的值变为101, 并以`j`的值作为本次`func`函数的返回值, 则`arr[1]`的值为101.
接着, 执行`func()`：此次的`j`保留了上次调用的终值101. 然后执行`j += g`, `j`的值变为104, 并以`j`的值作为本次`func`函数的返回值, 则`arr[0]`的值为104.
再然后, 执行`func()`：此次的`j`保留了上次调用的终值104. 然后执行`j += g`, `j`的值变为107, 并以`j`的值作为本次`func`函数的返回值, 则`arr[3]`的值为107 + 1 =108, `arr[2]`的值也为108.
之后, 执行`func()`：此次的`j`保留了上次调用的终值107. 然后执行`j += g`, `j`的值变为111, 并以`j`的值作为本次`func`函数的返回值, 则`arr[4]`的值为111.
到此为止, `arr`中的元素：`104`、`101`、`108`、`108`、`111`、`0`. 又因为`arr`实则是一个字符型数组, 所以这些整型数据会被解读为ASCII码, 在整型数据的位置存放的其实是其被解读为ASCII码时所对应的字符.
查表可得：

ASCII|104|101|108|111|0
:-:|:-:|:-:|:-:|:-:|:-:
对应字符|`'h'`|`'e'`|`'l'`|`'o'`|`'\0'`

最后, 执行`printf`函数来打印输出. `printf`函数内的占位符`%s`, 其参数为一个数组名`arr`, 在这里退化成了数组`arr`中首元素的地址, 即`arr[0]`的地址. 
又因为`printf`函数采用占位符`%s`打印的原理：接收`%s`对应的参数, 即一个地址, 从该地址的字符开始, 逐个打印输出字符, 直到遇到`'\0'`才结束打印输出.


所以`printf`函数先借助占位符`%s`打印输出：`"hello"`, 接着打印输出：`" linux\n"`.

## 9.宏函数指针
>观察程序结果, 说说程序运行的过程.
>```c
>#define CALL_MAIN(main, x) (*(int (*)(int))*main)(x)
>#define DOUBLE(x) 2*x
>int (*registry[1])(int);
>int main(int argc) {
>    if (argc > 2e3) return 0;
>    printf("%d ", argc + 1);
>    *registry = (int(*)(int))main;
>    CALL_MAIN(registry, DOUBLE(argc + 1));
>    return 0;
>}
>```
### (1).核心知识
* 宏定义的本质：`#define`是预处理命令, 在编译前进行文本替换, 不进行类型检查, 也不进行任何计算.
* 宏展开的副作用：若宏参数在宏定义中出现多次, 且传入参数包括`++`、`--`等, 展开后可能会多次执行, 导致逻辑错误.
* 递归调用：函数在其函数体内部, 直接或间接地调用自己, 这个现象称为递归. 当在第==n==层递归中, 需要调用第==n+1==层递归, 则第==n==层递归暂停, 先调用第==n+1==层递归：直到第==n+1==层递归完全返回后, 才会继续执行第==n==层递归暂停处之后的代码.
* 若有一个指针`arr`：那么`*arr`等价于`arr[0]`, 意义是访问指针所指向的元素. 
进一步地, `*(arr + i)`等价于`arr[i]`, 意义是让指针`arr`跨越i个元素后（元素类型取决于指针的类型, 若`arr`为整型指针, 则跨越的每个元素都是整型元素；若`arr`为字符型指针, 则跨越的每个元素都是字符型元素）, 再访问此时指针所指向的元素. 
所以当i为负数时, 如`*(arr - 1)`等价于`arr[-1]`, 意义是让指针`arr`向后跨越1个元素后, 再访问此时指针所指向的元素.
因此, 我们平时定义一个数组`arr`后, `arr[k]`其实是让数组名`arr`先退化为指向数组`arr`首元素的指针, 再让指针跨越k个元素, 再访问此时指针所指向的元素. 由此推出：定义数组`arr`后, `arr[k]`的意义是访问数组`arr`中第==1+k==个元素.
### (2).题目解析
这段代码的主要难点是类型的形式复杂, 比如多次出现了`*`, 但是`*`有多重含义：作为==乘法运算符==、作为==解引用操作符==、作为==指针变量的标志==.
在主函数外, 两行宏定义后, 分析`int (*registry[1])(int);`这一语句：`registry`是一个变量名, 所以先抛开其类型不谈, 需要明确这个语句是在定义`registry`这个变量. 

在变量定义时, 除去变量名的部分就是这个变量的类型.
 `registry`的类型为：`int (*[1])(int)`, 这个类型是数组类型. 数组的元素类型是`int (*)(int)`, 即“有1个`int`类型参数, 返回值为`int`类型”的函数的指针. ——函数指针数组
 区分：
比如 `int (*(*)[3])(int, int)`. ——函数指针数组的指针

进入主函数`main`时, 系统将`argc`的初值传递给`main`, 默认这个初值为1, 含义是命令行只有程序名这个唯一的参数. 

2e3实际上就是2000的科学计数法形式. 刚进入主函数时, `argc`的值为1, 显然`if`语句的条件为“假”, 则直接执行`if`语句的下一条语句, 打印输出：`"2 "`.

执行语句`*registry = (int(*)(int))main;`时：注意到`int(*)(int)`是一个函数指针类型, 对应的函数有1个`int`类型的参数, 返回值是`int`类型. 所以这里是先将`main`这个函数名理解为函数指针, 再把这个函数指针强制转换为`int(*)(int)`这样一个函数指针类型. 由于`*registry`等价于`registry[0]`,  所以之后会把强制转换得到的函数指针存放到函数指针数组`registry`中, 作为该数组的第1个元素.

宏展开后, 下一语句为：`(*(int (*)(int))*registry)(2*argc + 1);` 这里宏展开极其易错.
先执行`*registry`, 取出数组`registry`的第1个元素, 即`main`这个函数名.
再执行`(int (*)(int))main`, 把`main`这个函数名强制转换为`int(*)(int)`这样一个函数指针类型.
之后执行`*main`,得到`main`函数本身.
然后调用`main(2*argc + 1)`.
所以原语句等价于语句`main(2*argc + 1);`, 会出现递归调用, 此后将递归调用`main(3)`, `main(7)`, `main(15)`, `main(31)`…… 直到调用`main(2047)`, 此时`argc`的值为2047, 表达式`argc > 2e3`为“真”, 这层递归返回, 接着执行之前暂停的各层递归, 如`main(1023)`, `main(511)`, `main(255)`依次返回, 直到`main(1)`返回, 本程序结束.

由于调用`main(2047)`时, `if`语句的条件为“真”, 故这层递归会直接返回, 不会打印`"2048 "`.

## 10.拼接 排序 去重
>本题要求你编写以下函数, 不能改动`main`函数里的代码. 实现对`arr1`和`arr2`的拼接、排序和去重. 你需要自行定义`result`结构体并使用`malloc`手动开辟内存.

### (1).核心知识
* 变量向函数传参的两种方式：将变量==自身的值==作为实参，或者将变量的地址作为实参.
* 函数修改外部变量的必要条件：必须向函数传递外部变量的地址, 用指针接收外部变量的地址. 同时必须在函数内部对指针进行解引用操作以访问该外部变量.
* 点操作符`.`：用于访问结构体的某个成员元素.
* 箭头操作符`->`：借助`->`, 可以通过一个结构体指针来直接访问该结构体的某个成员元素. 比如先定义结构体类型`struct STUDENT`中有一个成员元素`int number`, 现在以`struct STUDENT`定义了结构体`student`, 并用类型为`struct STUDENT*`的结构体指针`p`接收了`student`的地址. 那么想要访问`student`的成员元素`int number`：`p->number`.

* `free`函数：用于释放所申请的内存空间.
* 若有一个指针`arr`：那么`*arr`等价于`arr[0]`, 意义是访问指针所指向的元素. 
进一步地, `*(arr + i)`等价于`arr[i]`, 意义是让指针`arr`跨越i个元素后（元素类型取决于指针的类型, 若`arr`为整型指针, 则跨越的每个元素都是整型元素；若`arr`为字符型指针, 则跨越的每个元素都是字符型元素）, 再访问此时指针所指向的元素.

因此, 我们平时定义一个数组`arr`后, `arr[k]`其实是让数组名`arr`先退化为指向数组`arr`首元素的指针, 再让指针跨越k个元素, 再访问此时指针所指向的元素. 由此推出：定义数组`arr`后, `arr[k]`的意义是访问数组`arr`中第==1+k==个元素.
### (2).题目解析 + 题目答案
```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>    //free函数和malloc函数都在头文件stdlib.h中声明, 所以不要忘了包含这个头文件




struct result  
{
	int* arr;    //用于存放动态数组中首元素的地址
	int len;    //用于存放动态数组的大小
};




void your_concat(int* arr1, int len1, int* arr2, int len2, struct result* result_p)    //此函数的功能：把两个数组拼接到动态数组中
{
	result_p->len = len1 + len2;    //动态数组的大小能恰好容纳所需拼接的数组中的元素即可

	result_p->arr = (int*)malloc((result_p->len) * (sizeof(int)));    //手动开辟一片内存, 从返回的地址开始, 恰好能存放两个数组中的所有元素
	//注意malloc函数所返回的指针是void*类型, 所以为了构造存放整型数据的动态数组, 则需把这个指针强制转换为int*类型
	if ((result_p->arr) == NULL)    //返回了一个空地址
	{
		printf("内存分配失败, 可能是内存不够了~");
		return;
	}

	for (int i = 0;i < len1;i++)    //循环遍历数组arr1和动态数组arr
	{
		result_p->arr[i] = arr1[i];    //把数组arr1中的所有元素存入动态数组arr中
	}

	for (int i = 0;i < len2;i++)    //循环遍历数组arr2和动态数组arr
	{
		result_p->arr[len1 + i] = arr2[i];    //把数组arr2中的所有元素存入动态数组arr中
	}

	return;
}




void print_result(struct result result)    //此函数的功能：展示现在动态数组中的元素
{
	printf("现在的数组arr：\n");

	for (int i = 0;i < (result.len);i++)
	{
		printf("arr[%d] = %d\n", i, result.arr[i]);
	}

	printf("\n");    //看起来更美观, 让两次动态数组的展示不要粘连

	return;
}




void your_sort(struct result* result_p)    //此函数的功能：让动态数组中的元素按从小到大的顺序排序
{
	for (int i = 0;i < (result_p->len) - 1;i++)    //这里是初学者最喜欢的冒泡排序：有n个元素时, 需要排序n-1趟
	{
		int change = 0;    //每趟定义一个临时变量change并初始化为0, 若某一趟结束时change仍为0, 说明本趟未发生交换, 那么已经排序完毕
		for (int j = 0;j < (result_p->len) - i - 1;j++)
		{
			if ((result_p->arr[j]) > (result_p->arr[j + 1]))
			{
				int value = 0;
				value = (result_p->arr[j + 1]);
				result_p->arr[j + 1] = (result_p->arr[j]);
				result_p->arr[j] = value;
				change = 1;    //由于发生了交换, 所以本趟的临时变量change为1 
			}
		}

		if (!change)
		{
			break;    //本趟的临时变量change为0时, 说明排序完毕, 不再需要排序了
		}
	}

	return;
}




void your_dedup(struct result* result_p)    //此函数的功能：让动态数组的元素只保留不重复的
{
	if ((result_p->len) <= 1)
	{
		return;
	}

	int j = 0;
	for (int i = 1;i < (result_p->len);i++)
	{
		if ((result_p->arr[i]) != (result_p->arr[j]))
		{
			j++;
			result_p->arr[j] = (result_p->arr[i]);
		}
	}
	//循环结束后, 对于数组arr：下标从0到j所对应的元素, 为去重后的元素, 共j+1个元素
	result_p->len = j + 1;    //更新动态数组的大小

	return;
}




int main() {
	int arr1[] = { 6, 1, 2, 1, 9, 1, 3, 2, 6, 2 };
	int arr2[] = { 4, 2, 2, 1, 6, 2 };
	int len1 = sizeof(arr1) / sizeof(arr1[0]);    //计算数组arr1的大小
	int len2 = sizeof(arr2) / sizeof(arr2[0]);    //计算数组arr2的大小
	struct result result;    //定义一个类型为struct result的结构体result
	struct result* result_p = &result;    //将结构体result的地址存入指针result_p中, 便于后续在其他函数内部操作结构体result
	your_concat(arr1, len1, arr2, len2, result_p);
	print_result(result);
	your_sort(result_p);
	print_result(result);
	your_dedup(result_p);
	print_result(result);
	free(result.arr);    //程序结束前, 释放动态数组arr所占用的内存空间
	return 0;
}
```

## 11.指针魔法
>用你智慧的眼睛, 透过这指针魔法的表象, 看清其本质.
>```c
>void magic(int(*pa)[6], int** pp) {
>      **pp += (*pa)[2];
>      *pp = (*pa) + 5;
>      **pp -= (*pa)[0];
>      *pp = (*pa) + ((*(*pa + 3) & 1) ? 3 : 1);
>      *(*pp) += *(*pp - 1);
>      *pp = (*pa) + 2;
>}
>int main() {
>    int a[6] = { 2, 4, 6, 8, 10, 12 };
>    int* p = a + 1,** pp =&p;
>    magic(&a,pp);
>    printf("%d %d\n%d %d %d\n%d %d\n",*p,**pp,a[1],a[2],a[3],a[5],p - a);
>    return 0;
>}
>```
### (1).核心知识
* 数组名的退化：数组名在参与运算、传参时会退化为指针，其指向为数组中首元素的地址.
* 若有一个指针`arr`：那么`*arr`等价于`arr[0]`, 意义是访问指针所指向的元素. 
进一步地, `*(arr + i)`等价于`arr[i]`, 意义是让指针`arr`跨越i个元素后（元素类型取决于指针的类型, 若`arr`为整型指针, 则跨越的每个元素都是整型元素；若`arr`为字符型指针, 则跨越的每个元素都是字符型元素）, 再访问此时指针所指向的元素. 
所以当i为负数时, 如`*(arr - 1)`等价于`arr[-1]`, 意义是让指针`arr`向后跨越1个元素后, 再访问此时指针所指向的元素.
因此, 我们平时定义一个数组`arr`后, `arr[k]`其实是让数组名`arr`先退化为指向数组`arr`首元素的指针, 再让指针跨越k个元素, 再访问此时指针所指向的元素. 由此推出：定义数组`arr`后, `arr[k]`的意义是访问数组`arr`中第==1+k==个元素.
* 条件表达式`条件 ? 表达式1 : 表达式2`：特指由三目运算符`? :`构成的表达式. 计算这个表达式的值时, 先判断条件为“真”还是“假”——若为“真”, 则以`表达式1`的值作为整个表达式的值；若为“假”, 则以`表达式2`的值作为整个表达式的值. 条件表达式可以被视为`if...else`语句的简化版.
* 
运算符|运算逻辑|
:-:|:-:
按位与运算符`&`|二目操作符, 从两个操作对象的二进制位的最低位开始, 有0得0, 全是1才得1
逻辑与运算符`&&`|二目操作符, 一假则假,  全真才真
### (2).题目解析
在主函数内：
先定义了一个整型数组`a`, 其中元素为：`2`, `4`, `6`, `8`, `10`, `12`.
又定义了一个指针`p`, 数组名`a`在表达式中发生数组名退化, 所以`p`指向数组`a`中的第2个元素.
还定义了一个二级指针`pp`, 用于存储指针`p`的地址.

接着调用`magic`函数, `magic`函数的两个形参：整型数组指针`pa`和整型二级指针`pp`.
`pa`接收了数组`a`的地址, `pp`接收了指针`p`的地址.

在`magic`函数内, 我们逐行来看：
第一行：先看`(*pa)`, 这里解引用指针`pa`, 访问的即数组`a`, 得到数组名`a`, 所以`(*pa)[2]`即`a[2]`. 再看`**pp`, 这里两次解引用指针`pp`, 第一次解引用得到指针`p`, 第二次解引用是对第一次解引用得到的指针`p`解引用, 会得到数组`a`中第2个元素`a[1]`. 那么这一行的语句等价于：`a[1] += a[2];`, 则`a[1]`的值更新为10.

第二行：先看`(*pa)`, 得到数组名`a`. 再看`*pp`, 这里解引用指针`pp`, 得到指针`p`. 那么这一行的语句等价于：`p = a + 5;`, 则更改指针`p`中所存储的地址, 使指针p指向数组`a`中第6个元素`a[5]`.

第三行：先看`(*pa)`, 得到数组名`a`, 所以`(*pa)[0]`即`a[0]`. 再看`**pp`, 第一次解引用得到指针`p`. 注意指针`p`中所存储的地址已经改变, 所以第二次解引用指针`p`时, 会得到数组`a`中第6个元素`a[5]`. 那么这一行的语句等价于：`a[5] -= a[0]`, 则`a[5]`的值更新为10.

第四行：等价于：`a + ( (*(a+3) & 1) ? 3 : 1)`, 进一步等价于：`a + ( (a[3] & 1) ? 3 : 1)`. ==这里注意不要把按位与运算符`&`看成逻辑与运算符`&&`了==. 
`a[3]`的值为8, 计算`8 & 1`：8的二进制表示为1000, 1的二进制表示为0001, 那么`8 & 1`的二进制表示为0000, 值为0, 为“假”. 
如果是把`&` 看成`&&`了, 8和1都是非0, 视为“真”, 那`8 && 1`的值为1, 为“真”. 
两个操作符虽然形似, 但从结果到运算逻辑都截然不同.  
现在条件表达式的条件为“假”, 则取1为整个表达式的值, 则又等价于`a + 1`. 那么这一行的语句等价于：`p = a + 1;` 又更改了`p`所存储的地址, 使`p`指向数组`a`中第2个元素.

第五行：那么这一行的语句等价于：`a[1] += a[0]`, 则`a[1]`的值更新为12.

第六行：那么这一行的语句等价于：`p = a + 2`, 又更改了`p`所存储的地址, 使`p`指向数组`a`中第3个元素`a[2]`.

最终数组`a`的元素：`2`, `12`, `6`, `8`, `10`, `10`
指针`p`指向数组`a`中第3个元素`a[2]`.
由于`p = a + 2`, 那么`p - a`的值为2.
综上：
`*p`即`a[2]`, 值为6.
`**pp`等价于`*p`, 即`a[2]`, 值为6.
`a[1]`的值为12.
`a[2]`的值为6.
`a[3]`的值为8.
`a[5]`的值为10.
`p - a`的值为2.

**12 6 8**

* 函数名：大部分情况下, 函数名可以被视为指向该函数的指针. 但`sizeof(函数名)`会直接报错, 而不是计算函数指针的大小.

|后缀|先将变量自身的值应用于表达式, 再对变量自增或自减
### (2).题目解析
打眼望去, 代码里出现了`sizeof(Node)`和`sizeof(union data)`, 分别计算结构体类型`struct node`和联合体类型`union data`的大小, 所以我们不妨在正式读代码之前就先简单计算一下~


当编译器默认对齐数为8时.
对于`union data`类型的联合体：
联合体成员|对齐数|偏移量|大小
|:-:|:-:|:-:|:-:
`void****p`|8|0|8（字节）
`char arr[20]`|1|0|20（字节）

64位系统下, 不管是几级指针, 其所存储的都是一个地址, 只要是地址大小就是8（字节）, 所以哪怕这里改成void*********p, 也不影响这个指针的大小是8（字节）.
计算这个联合体类型大小时, 有一个地方很容易出错：在其所有成员元素中, 对齐数的最大值是8, 而最大成员`char arr[20]`的大小是20（字节）, ==20并不是8的整数倍, 所以不能作为这个联合体的大小！==
于是我们从20向后找, 21, 22, 23, 24, 找到24恰好是8的整数倍, 那么`union data`类型的大小就是24（字节）.

对于`struct node`类型的结构体：
结构体成员|对齐数|偏移量|大小
|:-:|:-:|:-:|:-:
`int a`|4|0|4（字节）
`union data b`|8|8|24（字节）
`void (*use)(struct node* n)`|8|32|8（字节）
`char string[0]`|1|40|0（字节）

由于`struct node`类型的成员元素`char string[0]`大小为0（字节）, 所以由表可得：该类型的大小为40（字节）.

进入主函数后：
先定义了一个字符型指针`s`, 以一个常量字符串`"Your journey begins here!"`为`s`赋初值, 则`s`会存储这个常量字符串的地址, 也就是首字符`'Y'`的地址.

然后用`malloc`函数手动开辟了一片内存, 把返回的无类型指针强制转换为`Node*`类型, 即`struct node*`类型, 让指针`P`来接收. 这里`strlen(s) + 1`的“+1”是把常量字符串最后的隐式`\0`也计数计入, 这样最后开辟的内存中也能够放下这个`\0`.

之后调用`strcpy(P->string, s)`：指针`P`是`struct node*`类型, 所以这样一个结构体指针可以用`->`来直接访问对应结构体的成员. 这里的指针`P`其实对应了一个结构体, 我们记作`JIEGOUTI`.
这里的意思是, 把常量字符串放入刚开辟的内存中预留好的位置.

`P->use = func1`把函数`func1`的函数名, 作为函数指针放入了结构体`JIEGOUTI`的成员`use`中.

`P->a = sizeof(Node) * 50 + sizeof(union data)`把`=`右侧表达式的值放入了结构体`JIEGOUTI`的成员`a`中. 
由内存对齐的知识计算可得：`sizeof(Node)`的值是40, `sizeof(union data)`的值是24. 所以`a`的值是==40 × 50 + 24 = 2024==.

接下来遇到`while`语句, 其条件`P->a < 2028`此时为真, 那么执行循环体.
第一次进入循环：
`P->use`得到函数名`func1`, 接下来调用`func1(P)`.
在函数`func1`内部：先执行`node->use = func2`, 把函数`func2`的函数名, 放入了结构体`JIEGOUTI`的成员`use`中. 然后从`node->string`得到的地址开始打印字符串, 打印输出：`"Your journey begins here!\n"`.
`func1(P)`调用完毕后, 其实`P->a`的值并未改变, 所以接下来依旧执行循环体.
第二次进入循环：
`P->use`得到函数名`func2`, 接下来调用`func2(P)`.
在函数`func2`内部：先执行`node->use = func1`, 把函数`func1`的函数名, 放入了结构体`JIEGOUTI`的成员`use`中. 然后前缀`++`让`node->a`先自增, 值变为2025, 再把`node->a`的值打印出来, 那么会打印输出：`"2025\n"`.

不难发现：前两次循环打印输出：`"Your journey begins here!\n2025\n"`
`func1(P)`调用完毕后, `P->a`的值为2025, `while`语句的条件`P->a < 2028`依旧为真, 接下来会继续执行循环体.

第三次进入循环, 依旧是调用`func1(P)`, 把`func2`的函数名放入`use`中, 再打印输出：`"Your journey begins here!\n"` 由于未改变`node->a`的值, 所以结合前两次循环可以发现：只要进入循环后, 循环体内是调用`func1(P)`, 那一定也会进入下一次循环, 并且下一次循环体内是调用`func2(P)`, 显然两次循环会配套打印输出.
所以从前两次循环起, 把每两次循环记成一套循环, 那么只用看每套循环的情况.
第一套循环：打印输出：`"Your journey begins here!\n2025\n"`. 循环结束后`P->a`的值为2025.
第二套循环：打印输出：`"Your journey begins here!\n2026\n"`. 循环结束后`P->a`的值为2026.
第三套循环：打印输出：`"Your journey begins here!\n2027\n"`. 循环结束后`P->a`的值为2027.
第四套循环：打印输出：`"Your journey begins here!\n2028\n"`. 循环结束后`P->a`的值为2028.
因此第四套循环结束后, `while`语句的条件`P->a < 2028`变为“假”, 不再执行循环体.

最后执行`free(P)`释放手动申请的内存.

### 题目答案
>Q：你知道**cd**命令的用法与/ ~ -这些符号的含义吗？
>A：**cd**：用于在命令行中切换当前工作目录.
>/（根目录）：整个文件系统的最顶层.
>cd /：回到系统最顶层.
>~（用户主目录）：当前登录用户的家目录.
>cd ~：回到自己的家目录.
>-（上一次所在的目录）：用于在最近两次目录之间来回跳转.
>cd -：快速回到上一个你待过的目录, 适用于在两个文件夹之间频繁切换.

>Q：你知道Linux系统如何创建和删除一个目录呢？
>A：创建目录：mkdir 目录名.
>删除目录：
>①rmdir 目录名：删除空目录.
>②rm -r 目录名：递归删除目录及其内部所有文件和子目录, 需要确认.
>③rm -rf 目录名：强制递归删除, 不提示.

>Q：请问你还懂得哪些与**GNU/Linux**相关的知识呢？
>A：Linux 的目录结构是**单根树形结构**, 所有文件和目录都从根目录 / 开始. 它不像 Windows 那样有 C:\、D:\ 多个盘符, 而是把不同分区、设备、甚至远程文件系统都挂载到 / 下面的某个目录里.
