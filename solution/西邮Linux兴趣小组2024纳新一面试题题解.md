## 0.聪明的吗喽
>一个小猴子边上有100根香蕉, 它要走过50米才能到家, 每次它最多搬50根香蕉,（多了就拿不动了）, 它每走1米就要吃掉一根, 请问它最多能把多少根香蕉搬到家里.
>（提示：他可以把香蕉放下往返走, 但是必须保证它每走一米都能有香蕉吃. 也可以走到n米时, 放下一些香蕉, 拿着n根香蕉走回去重新搬50根.）
### (1).题目解析
小猴子每走1米就吃1根香蕉, 现在要让到家时剩下的香蕉最多, 所以需要==尽可能==地让小猴子少走路.

==如果没有==题目中“每次最多搬50根香蕉”的限制, 那么小猴子带着100根香蕉径直走50米时, 最终剩下的香蕉是最多的, 有50根.

但是现在有搬香蕉的数量限制, 所以要是让小猴子带着50根香蕉还是径直走50米, 走到家的时候香蕉也全进肚子了, 连一根香蕉也没带回去. 因为要保证“每走一米都能有香蕉吃”, 所以小猴子想走路还必须得有香蕉, 那现在想回出发点拿香蕉都回不去. 
要是带香蕉不够50根还是想径直走50米的话, 半路上香蕉就全没了, 小猴子在半路直接动不了了.

综上可知：小猴子必须得在途中的某个地方把身上的香蕉==先放下一部分==, 再带着够自己走回去的香蕉, 回出发点去拿一次香蕉再出发, 才有机会在到家的时候身上还有剩余的香蕉. ==在这个前提下==, 需要==尽可能==让小猴子少走路, 那么就尽量让小猴子每次出发时带的香蕉尽可能多, 也就是带50根香蕉, 这样让小猴子有可能仅用两次就把出发点的香蕉都搬走.

假设在出发点n米处, 小猴子放下手里的香蕉, 并且每次出发会带上50根香蕉：
从出发点第一次到n米处, 小猴子会消耗n根香蕉, 然后由于要再返回出发点, 又要走n米, 所以接下来应该带在身上n根香蕉再折返, 那么可以在n米处放下的香蕉最多为==50 - 2n==根.
返回出发点后, 再带上50根香蕉出发, 又走到n米处时, 又消耗了n根香蕉, 那此时小猴子身上的香蕉有==50 - n==根, 已经放下了==50 - 2n==根, 总共有==50 - n + 50 - 2n = 100 - 3n==根. 
为了让小猴子少走路, 别再回出发点拿香蕉了, 这里需要保证==100 - 3n ≤ 50==, 这样的话小猴子就可以一口气扛着这些香蕉美美回家了.
解得==n ≥ 16.666...== n显然只能为正整数, 所以==n = 17==. 
那第二次到==n = 17==米处时, 总共有==100 - 3n = 49==根香蕉, 接下来小猴子一次性拿着这49根香蕉向家径直走==50 - n = 33==米, 消耗33根香蕉后, 还剩下==49 - 33 = 16==根香蕉.
### (2).题目答案
>Q：请问它最多能把多少根香蕉搬到家里？
>A：16根.

## 1.西邮Linux欢迎你啊
>请解释以下代码的运行结果.
>```c
>int main() {
>    unsigned int a = 2024;
>    for (; a >= 0; a--)
>        printf("%d\n", printf("Hi guys! Join Linux - 2%d", printf("")));
>    return 0;
>}
>```
### (1).核心知识
* `printf`函数的返回值：调用后成功打印输出的字符总数. 当打印输出发生错误时, 则会返回一个负值.
* 链式访问：若函数`functionA`调用后的返回值作为另一个函数`functionB`的参数, 则前者被视为内层函数, 后者被视为外层函数. 内层函数先执行, 接着其返回值再作为外层函数的参数.
* 溢出现象：无符号整数（`unsigned int`类型）的最小值为0, 当达到最小值后, 继续让无符号整数减一会发生溢出, 得到一个很大的无符号整数.
### (2).题目解析
首先定义了无符号整型变量`a`, 并以`a >= 0`作为`for`语句的条件, 同时在`for`语句的每次循环结束后, 执行`a--`, 即让`a`自减.
 
那么自从首次执行`for`语句的循环体后, 每次循环后`a`会减小. 直至在某次循环开始时`a`的值为0, 再进入该循环, 那本次循环后再执行`a--`会使`a`的值变成一个很大的无符号整数, 那么`for`语句的条件`a >= 0`依旧为“真”, 会继续循环下去.
 
显然`a >= 0`永远成立, 那么实则陷入了死循环.

第一次循环中：
出现链式访问, 那么会先执行内层函数, 后执行外层函数. 
因此, 会先执行`printf("")`, 什么都没有打印出来, 那么该`printf`函数的返回值为0.
接着, 会执行`printf("Hi guys! Join Linux - 2%d", 0)`, 打印输出：`"Hi guys! Join Linux - 20"`, 由于成功打印的字符有：`'H'`、`'i'`、`' '`、`'g'`、`'u'`、`'y'`、`'s'`、`'!'`、`' '`、`'J'`、`'o'`、`'i'`、`'n'`、`' '`、`'L'`、`'i'`、`'n'`、`'u'`、`'x'`、`' '`、`'-'`、`' '`、`'2'`、`'0'`, 共24个字符, 那么该`printf`函数的返回值为24.
最后, 会执行`printf("%d\n", 24)`, 打印输出：`"24\n"`.
那么第一次循环的打印输出：`"Hi guys! Join Linux - 2024\n"`. 
不难发现：每次循环的打印输出内容是不变的, 与循环次数无关. 
所以程序运行后, 将不断循环打印输出：`"Hi guys! Join Linux - 2024\n"`.

## 2.眼见不一定为实
>输出为什么和想象中不太一样？
>你了解`sizeof()`和`strlen()`吗？他们的区别是什么？
>```c
>int main() {
>    char p0[] = "I love Linux";
>    const char *p1 = "I love Linux\0Group";
>    char p2[] = "I love Linux\0";
>    printf("%d\n%d\n", strcmp(p0, p1), strcmp(p0, p2));
>    printf("%d\n%d\n", sizeof(p0) == sizeof(p1), strlen(p0) == strlen(p1));
>    return 0;
>}
>```
### (1).核心知识
* 编译器在字符串的末尾会自动添加一个隐式的字符`'\0'`.
* 转义字符`'\0'`：具有截断作用, 即在字符串字面量中, 会被解析为字符串的结束符, 因此无论后面是否有其他字符, 在使用字符串处理函数时, 遇到`'\0'`总会立即停止解析.
* `strcmp`函数：用于比较两个字符串, 从两个字符串的首字符开始, 逐一比较各字符的ASCII码值, 直到遇到不同的字符或遇到`'\0'`为止. 例如`strcmp(str1, str2)`, `str1`和`str2`分别为字符串X、Y的指针, 若没有比较出不同, 则`strcmp`函数返回0；若比较出不同, 当结果为X较大时, `strcmp`函数返回正值, 而当结果为X较小时, `strcmp`函数返回负值.
* `sizeof`运算符：用于操作数据类型或变量, 计算其在内存中所占的大小.
* `strlen`函数：用于计算字符串的长度, 但不计入`'\0'`.
* 数组名的退化：数组名在参与运算、传参时会退化为指针，其指向为数组中首元素的地址.
* 指针变量的大小：即其所存储的地址的大小. 在64位系统下, 固定为==8==个字节；在32位系统下, 固定为4个字节.
### (2).题目解析
首先定义了两个字符型数组`p0`和`p2`, 并以`""`来初始化. 这样初始化的话, 有个容易错的地方：由于编译器会自动在末尾追加一个隐式的`'\0'`, 因此在初始化后, 这个隐式的`'\0'`也会成为该数组的一个元素.
还定义了字符型指针`p1`, 用于存储常量字符串`"I love Linux\0Group"`的地址, 其实就是这个常量字符串的首元素`'I'`的地址.

对于`strcmp(p0, p1)`：从`p0`和`p1`的首字符开始, 逐一比较各字符的ASCII码值, 直到遇到不同的字符或遇到`'\0'`为止. 到`'\0'`之前, 未发现不同字符, 所以该`strcmp`函数的返回值为0.
对于`strcmp(p0, p2)`：从`p0`和`p2`的首字符开始, 逐一比较各字符的ASCII码值, 直到遇到不同的字符或遇到`'\0'`为止. 到`'\0'`之前, 未发现不同字符, 所以该`strcmp`函数的返回值为0.

对于`sizeof(p0)`：`p0`为一个数组名, 由于`()`内`p0`未参与运算与传参, 所以此处`p0`不会退化为指针, 那么`sizeof`运算符会计算数组`p0`的大小. 又因为`p0`中存放了`'I'`、`' '`、`'L'`、`'o'`、`'v'`、`'e'`、`' '`、`'L'`、`'i'`、`'n'`、`'u'`、`'x'`、`'\0'`, 共13个字符, 每个字符大小为1字节, 那么`sizeof(p0)`的值为13.
对于`sizeof(p1)`：`p1`为一个指针, 在64位系统下, 指针的大小为8字节, 那么`sizeof(p1)`的值为8.

对于`strlen(p0)`：`p0`为一个数组名, 在此处由于向`strlen`函数传参, 所以退化为指向字符型数组`p0`首元素的指针. 从`p0`这个地址对应的字符开始逐一计数, 遇到`'\0'`停止且计数不包括`'\0'`, 共12个字符. 因此`strlen(p0)`的返回值为12.
对于`strlen(p1)`：从`p1`这个地址对应的字符开始逐一计数, 遇到`'\0'`停止且计数不包括`'\0'`, 共12个字符. 因此`strlen(p1)`的返回值为12.



### (3).题目答案

## 3.1.1 - 1.0 != 0.1
>为什么会这样, 除了下面给出的一种方法, 还有什么方法可以避免这个问题？
>```c
>int main() {
>    float a = 1.0, b = 1.1, ex = 0.1;
>    printf("b - a == ex is %s\n", (b - a == ex) ? "true" : "false");
>    int A = a * 10, B = b * 10, EX = ex * 10;
>    printf("B - A == EX is %s\n", (B - A == EX) ? "true" : "false");
>}
>```
### (1).核心知识
* 数据在内存中以二进制形式存放.
* 浮点数的二进制表示：对于浮点数, 很多十进制的==有限小数==转换成二进制后是==无限循环小数==.
* 浮点数的精度丢失（舍入误差）：由于浮点数类型的所占的内存空间有限, 故在把浮点数用二进制表示后, 无法存储无限循环下超出精度的部分, 因此会对这部分进行“四舍五入”（舍入到最近的偶数）, 这样会导致存储的浮点数只是真实值的==近似值==.
* 浮点数的比较：由于浮点数可能会精度丢失（注意也可能不丢失, 见题目解析）, 所以比较两个浮点数是否相等时, 不建议使用`==`.
* 条件表达式`条件 ? 表达式1 : 表达式2`：特指由三目运算符`? :`构成的表达式. 计算这个表达式的值时, 先判断条件为“真”还是“假”——若为“真”, 则以`表达式1`的值作为整个表达式的值；若为“假”, 则以`表达式2`的值作为整个表达式的值. 条件表达式可以被视为`if...else`语句的简化版.
### (2).题目解析
先定义单精度浮点型变量`a`、`b`、`ex`, 并对`a`、`b`、`ex`分别赋值1.0、1.1、0.1. 存储时会把所赋的值转换为二进制, 变为无限循环小数. 同时由于有限的精度, 所以发生截断, 实际存储的值会产生误差. 
那么`b - a`的值通常不等于`ex`的值, 故表达式`b - a == ex`通常为“假”.

而若重新定义整型变量`A`、`B`、`EX`, 分别接收`a * 10`、`b * 10`、`ex * 10`这3个表达式的值, 而这3个表达式的值是单精度浮点型, 所以会发生浮点数的舍入, 即3个表达式最终会得到3个整数值10、11、1.
那么`B - A`的值显然等于`EX`的值, 故表达式`B - A == EX`为“真”.
### (3).题目答案
* 问题回答
>Q：还有什么办法可以避免这个问题？
>A：引入极小值进行比较：首先包含头文件`math.h`, 然后在比较`a`与`b`两个浮点数是否相等时, 先引入一个极小值`epison`, 其值通常取==1e-6==或==1e-9==, 接着利用关系运算符`<`来判断：`fabs(a - b) < epison`, 意义是判断`a`与`b`两个值的绝对值之差是否足够小. 若为“真”, 则足够小, 认为`a`与`b`这两个浮点数是相等的；若为“假”, 则认为`a`与`b`这两个浮点数是不相等的.

* 输出结果
**b - a == ex is false**
**B - A == EX is true**

## 4.听说爱用位运算的人技术都不太差
>解释函数的原理, 并分析使用位运算求平均值的优缺点.
>```c
>int average(int nums[], int start, int end) {
>     if (start == end)
>        return nums[start];
>     int mid = (start + end) / 2;
>     int leftAvg = average(nums, start, mid);
>     int rightAvg = average(nums, mid + 1, end);
>     return (leftAvg & rightAvg) + ((leftAvg ^ rightAvg) >> 1);
>}
>```
### (1).核心知识
* 位运算：
1.按位与`&`：二目操作符, 从两个操作对象的二进制位的最低位开始, 有0得0, 全是1才得1.
2.按位异或`^`：二目操作符, 从两个操作对象的二进制位的最低位开始, 位相同得0, 位不同得1.
3.右移`>>`：将操作对象的二进制位全部右移, 超出的低位丢弃, 剩余的高位补0.

### (2).题目解析
现在有任意两个正整数==x==和==y==, 在二进制表示下, ==x==和==y==在某一数位==i==的值只可能是0或者1.
显然让==x==与==y==相加, 可以得到==x + y==, 那么对于==x + y==：
①==x==和==y==在数位==i==上的值都是1：对==x + y==在数位==i==上的贡献为2.
②==x==和==y==在数位==i==上的值, 一个为1, 一个为0：对==x + y==在数位==i==上的贡献为1.
③==x==和==y==在数位上的值都是0：对==x + y==在数位==i==上的贡献为0.
进一步可以推出, 对于(x + y) / 2：
①==x==和==y==在数位==i==上的值都是1：对(x + y) / 2在数位==i==上的贡献为1.
②==x==和==y==在数位==i==上的值, 一个为1, 一个为0：对(x + y) / 2在数位==i - 1==上的贡献为1.
③==x==和==y==在数位上的值都是0：对(x + y) / 2在数位==i==上的贡献为0.

接下来, 我们主要借助按位与`&`和按位异或`^`.
①`x & y`：所得结果中, 数位==i==的值若为1, 说明==x==和==y==在数位==i==上的值都为1. 那么`x & y`实际上就是==x==和==y==对(x + y) / 2在数位==i==上的贡献情况.
②`x ^ y`：所得结果中, 数位i的值若为1, 说明==x==和==y==在数位上的值, 一个为1, 一个为0. 那么`x ^ y`实际上就是==x==和==y==对==x + y==在数位==i==上的贡献情况, 因此`(x ^ y) >> 1`实际上就是==x==和==y==对(x + y) / 2在数位=i==上的贡献情况.

综上可得：`x & y + x ^ y`的值就是( x + y) / 2的值. 
以上则为借助位运算求两数平均值.

现在我们知道了怎么借助位运算求两数平均值, 那么我们怎么写出题目代码的递归函数呢？

如果想计算数组在某个区间的平均值, 假设区间的左端点的元素其对应下标为`start`, 区间的右端点的元素其对应下标为`end`, 左端点的元素的地址为`nums`, 那么我们可以试着写一个函数`average(nums, start ,end)`, 要求返回值是区间的平均值（运用数学归纳法的思想, 假设此时函数`average`立刻拥有了这个功能）.
显然当`start`与`end`相等时, 区间的平均值为`nums[start]`的值或`nums[end]`的值.
当`start`与`end`不相等时, 那么可以把这个区间再均分成左右两个区间, 这样的话, 两个区间各自的平均值的平均值就是原区间的平均值, 那么我们只需再借助`average`函数来分别求两个区间各自的平均值.
再借助`average`函数分别计算出左右两区间各自的平均值后, 可以采用位运算求这两个平均值的平均值, 所得即原区间的平均值. 

### (3).题目答案
* 问题回答
>Q：分析使用位运算求平均值的优缺点.
>A：
>优点：当两个数接近最大值时, 采用常规运算求平均值, 在求和时会溢出；采用位运算求平均值, 计算的过程值都小于所给的两个数, 因此不会发生溢出.
>缺点：
>①可读性差, 增加了维护成本和团队沟通成本.

## 5.全局还是局部!!!
>先思考输出是什么, 再动动小手运行下代码, 看跟自己想得结果一样不一样>-<
>```c
>int i = 1;
>static int j = 15;
>int func() {
>     int i = 10;
>     if (i > 5) i++;
>     printf("i = %d, j = %d\n", i, j);
>     return i%j;
>}
>int main() {
>     int a = func();
>     printf("a = %d\n", a);
>     printf("i = %d, j = %d\n", i, j);
>     return 0;
>}
>```
### (1).核心知识
* `static`关键字：
 修饰局部变量时, `static`局部变量无论函数调用多少次, 只初始化一次；同时`static`局部变量的生命周期延长, 每次函数调用时可以保留上次调用的终值；但`static`局部变量的作用域不变, 意味着在定义其的函数之外, `static`局部变量无法被直接使用；
修饰全局变量时, `static`全局变量从外部链接属性变为内部链接属性, 即作用域被限制在当前源文件内, 其他文件无法访问这个变量.
* 当局部变量和全局变量同名时, 局部变量优先：程序在函数内部执行时, 内层作用域会“屏蔽”外层作用域的同名变量, 优先使用函数内部的局部变量.
### (2).题目解析
在主函数外, 定义了全局变量`i`和全局变量`j`. `i`的初值为1, `j`的初值为15. 其中, `j`由关键字`static`修饰, 那么`j`为`static`全局变量. 这里注意`static`修饰全局变量和修饰局部变量的效果是有区别的, 不要混淆.

进入主函数后：
先执行`func()`. 在`func`函数内部, 先定义了局部变量`i`并赋初值为10. 
由于这里的局部变量`i`和之前的全局变量`i`同名, 那么在这个函数中, 直接使用现在定义的局部变量`i`, 而原先定义的全局变量`i`将会被“屏蔽”, 直到`func`函数调用结束后, 局部变量`i`被销毁, 才结束对全局变量`i`的“屏蔽”.

接下来, `if`语句的条件`i > 5`显然为真, 那么执行`i++`, `i`的值更新为11.
 
然后, 打印输出`i`和`j`的值. 
此时, `i`的值是局部变量`i`的值, 即11；
由于在`func`函数内部并未创建与全局变量`j`同名的局部变量`j`, 那这里会直接使用全局变量`j`, 那么`j`的值是全局变量`j`的值, 即15.

接着, `func`函数的返回值为`i % j`的值, 即==11 % 15 = 11==.
那么初始化整型变量`a`后, `a`的值为11.

`func`函数调用结束, 在其内部定义的局部变量`i`被销毁, 之后将使用全局变量`i`.

之后, 打印输出`a`的值, 即11. 又打印输出`i`和`j`的值, 而`i`和`j`此时使用全局变量`i`和全局变量`j`, 那么`i`和`j`的值分别为1和15.


### (3).题目答案

* 输出结果
**i = 11, j = 15**
**a = 11**
**i = 1, j = 15**

## 6.指针的修罗场：改还是不改，这是个问题
>指出以下代码中存在的问题, 并帮粗心的学长改正问题.
>```c
>int main(int argc, char **argv) {
>     int a = 1, b = 2;
>     const int *p = &a;
>     int * const q = &b;
>     *p = 3, q = &a;
>     const int * const r = &a;
>     *r = 4, r = &b;
>     return 0;
>}
>```
### (1).核心知识
* `const`关键字：让其所修饰的变量在初始化后的值不能再被更改. 当使用`const`关键字修饰指针时：`const`在`*`左边则修饰指针所指向的内容, 使指针成为“常量指针”；`const`在`*`右边则修饰指针的指向, 使指针成为“指针常量”.
### (2).题目解析 + 题目答案
分别定义了整型指针`p`、`q`、`r`, 三个指针分别指向整型变量`a`、`b`、`r`. 在定义这些整型指针时, 全都使用了关键字`const`来修饰, 根据修饰位置不同, 得到的指针也有不同的限制.

`p`：常量指针. 指针`p`所指向的内容不可变, 即`a`不可变, 则`*p = 3`不合法.

`q`：指针常量. 指针`q`的指向不可变, 也就是说指针`q`存放了`b`的地址后, 不能再换而存放其他整型变量的地址, 则`q = &a`不合法.

`r`：既是常量指针, 又是指针常量. 指针`r`所指向的内容不可变, 即`a`不可变, 则`*r = 4`不合法. 同时, 指针`r`的指向不可变, 也就是说指针`r`存放了`a`的地址后, 不能再换而存放其他整型变量的地址, 则`r = &b`不合法.

## 7.物极必反？
>你了解`argc`和`argv`吗, 这个程序里的`argc`和`argv`是什么？
>程序输出是什么？解释一下为什么.
>```c
>int main(int argc, char *argv[]) {
>     while (argc++ > 0);
>     int a = 1, b = argc, c = 0;
>     if (--a || b++ && c--)
>        for (int i =0; argv[i] != NULL; i++)
>            printf("argv[%d] = %s\n", i, argv[i]);
>     printf("a = %d, b = %d, c = %d\n", a, b,c);
>     return 0;
>}
>```
### (1).核心知识
* `int argc`：初值为命令行参数的数量. 默认情况下, 程序名本身算作第1个参数, 所以`argc`的值至少为1.
*  
|++和- -|效果
|:-:|:-:
|前缀|先让变量自增或自减, 再将变化后的变量的值应用于表达式
|后缀|先将变量自身的值应用于表达式, 再对变量自增或自减

* 溢出现象：有符号整数（`int`类型）的运算结果如果超出其表示范围（`INT_MIN`到`INT_MAX`）, 则实际结果取决于编译器和硬件.
* 逻辑或运算符`||`：计算表达式`A||B`时, 会先执行表达式`A`, 并判断`A`的值是“真”还是“假”——若为“真”, 则表达式`A||B`的值为“真”, 不会进一步执行表达式`B`；若为“假”, 则进一步执行表达式`B`. 若表达式`B`的值为“真”, 则表达式`A||B`的值为“真”. 若表达式`B`的值为“假”, 则表达式`A||B`的值为“假”.
上面的表述通常被概括为逻辑或运算符`||`的==“短路性质”==, 通俗地讲, 表达式`A||B`一真则真, 全假才假. 逻辑与运算符`&&`也具有该性质, 表达式`A&&B`一假则假, 全真才真.


### (2).题目解析
`argc`是命令行参数的数量, 默认情况下, 只有程序名这一个参数, 此时`argc`值为1.
先遇到`while`语句, 在其条件中, 后缀`++`使`argc`先将值应用于条件“真”与“假”的判断, 再进行一次自增. 此时`argc`的值为1, 条件为“真”, 接下来会执行循环体, 并且 `argc`的值会更新为2. 
但是循环体为一个空语句, 那么会再次回到`while`语句之前. 此时`argc`的值为2, 条件为“真”, 接下来又会执行循环体, 并且`argc`的值会更新为3.
不难发现, 接下来会重复执行循环体, 直至回到`while`语句之前时, `argc`的值达到`INT_MAX`, 那这时进入循环后, `argc`的值会溢出为一个极大的负数, 则再次回到`while`语句之前的条件为“假”, 不再执行循环体.

之后, 定义了整型变量`a`、`b`、`c`, `a`的值为1, `b`的值为`argc`的值, `c`的值为0.

又遇到`if`语句, `if`语句的条件等价于：`((--a || b++) && c--)`. 
①先计算表达式`--a || b++`. 
自左向右进行判断：先执行`--a`, `a`先进行自减, `a`的值更新为0, 再将`a`现在的值应用于表达式.
那么`||`的左值为“假”, 将会继续执行右侧表达式`b++`, 将`b`的值先应用于表达式, 负数为非0则视为“真”, 那么`(--a || b++)`的值为“真”, 并且`b`的值更新.
②再计算表达式`1 && c--`.
 此时, `&&`的左值为“真”, 将会继续执行右侧表达式`c--`, 将`c`的值先应用于表达式, 那么整个条件为“假”, 不会执行`if`语句下的语句, 并且`c`的值更新为-1.

最后打印`a`、`b`、`c`的值, `a`的值为0, `b`的值为一个很大的负数, `c`的值为-1. 这里注意`a`、`b`、`c`的值, 在定义之后, 都在判断`if`语句的条件时更新过了.


### (3).题目答案
* 输出结果
**a = 0, b = -2147483646, c = -1**

## 8.指针？数组？数组指针？指针数组
>在主函数中定义如下变量：
>```c
>int main() {

### (1).核心知识
* 数组名的退化：数组名在参与运算、传参时会退化为指针, 其指向为数组中首元素的地址.
* `sizeof`运算符：用于操作数据类型或变量, 计算其在内存中所占的大小.
* 指针变量的大小：即其所存储的地址的大小. 在64位系统下, 固定为==8==个字节；在32位系统下, 固定为4个字节.
### (2).题目解析 + 题目答案
轻松读懂这段代码的关键是：能够清晰地区分指针数组（可以存储指针的数组）和数组指针（指向某个数组的指针）.
定义`a`是一个数组, 装有2个整型数据, 初始化使`a`中的元素为`4`, `8`.
定义`b`是一个指针, 指向一个装有2个整型数据的数组, 初始化使`b`存储数组`a`的地址.
定义`c`是一个数组, 装有2个整型指针, 初始化使`c`存储了2个数组名`a`, `a + 1`, 这里发生了数组名退化, 二者依次表示指向数组`a`首元素的指针、指向数组`a`第二个元素的指针.

现在分析题目所给表达式.
`a`：数组名, 由于作为函数`printf`的参数, 所以会退化为指向数组`a`首元素的指针, 实质为一个地址.
`a + 1`：为指向数组`a`第2个元素的指针, 实质为一个地址.
`&a`：为数组`a`的地址.
`&a + 1`：为一个地址, 当前位置相比于数组`a`的地址, 跨过了整个数组`a`.
`*(a + 1)`：`a + 1`是指向数组`a`第2个元素的指针, 那么解引用`a + 1`后, 得到数组`a`中第2个元素`a[1]`.
`sizeof(a)`：计算数组`a`的大小, 为8个字节.
`sizeof(&a)`：计算数组`a`的地址的大小, 为8个字节.
`*b`：解引用指针`b`后, 得到数组`a`, 其实就是数组`a`的数组名, 这里也会退化成指向数组`a`首元素的指针, 实质为一个地址.
`*b + 1`：由上可知, 这里等价于`a + 1`, 为指向数组`a`第2个元素的指针, 实质还是一个地址.
`b`：指针, 实质为一个地址.
`b + 1`：相比于指针`b`, 跨过了整个数组`a`并指向了当前位置, 实质为一个地址.
`*(*b + 1)`：由上可知, `*b + 1`是指向数组`a`第2个元素的指针, 那么解引用`*b + 1`后, 得到数组`a`中第2个元素`a[1]`.
`sizeof(*b)`：由上可知, 这里等价于`sizeof(a[0])`,计算数组`a`首元素`a[0]`的大小, 为4个字节.
`sizeof(b)`：计算指针`b`的大小, 为8个字节.
`c`：数组名, 退化为指向数组`c`首元素的指针, 实质为一个地址. 数组`c`存储了2个指针, 在64位环境下, 指针大小为8字节, 则数组大小为16字节.
`c + 1`：为指向数组`c`第2个元素的指针, 实质为一个地址.
`&c`：为数组`c`的地址.
`&c + 1`：为一个地址, 当前位置相比于数组`c`的地址, 跨过了整个数组`c`.
`**(c + 1)`：这里对指针`c + 1`进行了两次解引用. `c + 1`是指向数组`c`第2个元素的指针, 那么解引用`c + 1`后, 得到数组`c`中第2个元素`c[1]`, 即`a + 1`. 再对`a + 1`解引用, 得到数组`a`中第2个元素`a[1]`, 即`8`.
`sizeof(c)`：计算数组`c`的大小, 为16个字节.
`sizeof(&c)`：计算数组`c`的地址的大小, 为8个字节.

## 9.嘻嘻哈哈，好玩好玩
>在宏的魔法下, 数字与文字交织, 猜猜结果是什么？
>```c
>#define SQUARE(x) x*x
>#define MAX(a, b) (a>b) ? a : b;
>#define PRINT(x) printf("嘻嘻, 结果你猜对了吗, 包%d滴\n", x);
>#define CONCAT(a, b) a##b
>int main() {
>     int CONCAT(x, 1) = 5;
>     int CONCAT(y, 2) = 3;
>     int max = MAX(SQUARE(x1 + 1), SQUARE(y2))
>     PRINT(max)
>     return 0;
>}
>```
### (1).核心知识
* 宏定义的本质：`#define`是预处理命令, 在编译前进行文本替换, 不进行类型检查, 也不进行任何计算.
* 宏展开的副作用：若宏参数在宏定义中出现多次, 且传入参数包括`++`、`--`等, 展开后可能会多次执行, 导致逻辑错误.
* `##`：预处理器专属的运算符. 预处理器在展开宏时, 如果遇到`a##b`, 会直接把参数`a`和参数`b`对应的纯文本拼接在一起, 形成一个全新的标识符.
* 条件表达式`条件 ? 表达式1 : 表达式2`：特指由三目运算符`? :`构成的表达式. 计算这个表达式的值时, 先判断条件为“真”还是“假”——若为“真”, 则以`表达式1`的值作为整个表达式的值；若为“假”, 则以`表达式2`的值作为整个表达式的值. 条件表达式可以被视为`if...else`语句的简化版.

### (2).题目解析
进入`main`函数, 展开所有宏, 则运行后会依次执行以下语句：
`int x1 = 5;` ——语句1
`int y2 = 3;` ——语句2
`int max = (x1 + 1 * x1 + 1 > y2 * y2) ? x1 + 1 * x1 + 1 : y2 * y2;` ——语句3
`printf("嘻嘻, 结果你猜对了吗, 包%d滴\n", max);` ——语句4


执行语句1和语句2后, 定义了整型变量`x1`与`y2`, 初值分别为5和3.
执行语句3时, 先判断条件表达式的条件`(x1 + 1 * x1 + 1 > y2 * y2)`, 此时`x1`和`y2`的值分别为5和3, 那么==x1 + 1 * x1 + 1 = 5 + 1 × 5 + 1 = 11==, ==y2 * y2 = 3 × 3 = 9==, 由于==11 > 9==, 则条件为“真”, 那么就以`x1 + 1 * x1 + 1`的值作为整个条件表达式的值. 
因此整个条件表达式的值为11, 则此处定义的整型变量`max`的值为11.
执行语句4时, `max`的值为11, 所以打印输出：`"嘻嘻, 结果你猜对了吗, 包11滴\n"`.

### (3).题目答案

**嘻嘻, 结果你猜对了吗, 包11滴**

## 11.猜猜我是谁
>在指针的迷宫中, 五个数字化身为神秘的符号, 等待被逐一揭示.
>```c
>int main() {
>     void *a[] = {(void *)1, (void*)2, (void*)3, (void*)4, (void*)5};
>     printf("%d\n", *((char*)a + 1));
>     printf("%d\n", *(int *)(char *)a + 1);
>     printf("%d\n", *((int *)a + 2));
>     printf("%lld\n", *((long long *)a + 3));
>     printf("%d\n", *((short *)a + 4));
>     return 0;
>}
>```
### (1).核心知识
* 大端存储与小端存储：
1.**大端存储**：数据的低位字节存储在高地址处, 高位字节存储在低地址处.
2.**小端存储**：数据的低位字节存储在低地址处, 高位字节存储在高地址处.
### (2).题目解析
先定义了一个数组`a`, 数组`a`中存放了5个`void*`类型的指针, 并且这些指针都是由整型数据强制转换得来的.

指针变量的值是地址, 在64位系统下, 地址通常由16进制表示, 大小为8个字节, 如0xFF000A3300998845.
由上可知：把`int`类型数据强制转换为`void*`的指针, 则需把原先的数用16进制表示, 并写成8个字节的形式. 由此, 我们可以写出数组`a`中所有指针的值：==0x0000000000000001==, ==0x0000000000000002==, ==0x0000000000000003==, ==0x0000000000000004==, ==0x0000000000000005==.

采用小端存储时：数据的地址, 是相对而言的低地址. 而从地址访问数据时, 是在前往相对而言的高地址. 
由于采用小端存储会把低位字节存储在低地址处, 所以访问数据时, 从这个数据的地址开始, 也就是从低地址开始, 也就会先访问其低位字节, 再访问高位字节. 
那么, 又因为数组中数据的存放是连续的, 我们从低地址开始, 可以写出数组`a`中五个指针的值在内存中大致的存放情况：==0100000000000000 0200000000000000 0300000000000000 0400000000000000 0500000000000000==.

将指针强制转换其他类型的指针后, 指针所存储的地址是不变的, 那改变的是什么呢？把指针转换为其他类型的指针后, 新类型在内存中的大小与之前类型在内存中的大小不同的话, 那么指针的步长和访问权限也会不同.
以整型指针`int * p`为例：
若现在有指针`p + 1`, 那么`p + 1`相对于`p`会跨越1个整型数据, 即4个字节, 这里的“4个字节”就可以认为是指针`p`此时的步长；若现在解引用指针`p`, 即`*p`, 那么将从`p`所存储的地址开始, 访问1个整型数据, 即4个字节, 这里的“4个字节”就可以认为是指针`p`此时的访问权限.
那么现在把整型指针`p`强制转换为字符型指针, 即`(char *)p`, 此时`p`所存储的地址依旧不变. 但是, 若现在有指针`p + 1`, 那么`p + 1`相对于`p`会跨越1个字符型数据, 即1个字节, 显然指针`p`的步长发生了改变；若现在解引用指针`p`, 即`*p`, 那么将从`p`所存储的地址开始, 访问1个整型数据, 即1个字节, 显然指针`p`的访问权限发生了改变.

有了前面的铺垫, 我们面对底下一连串的强制转换, 便可以迎刃而解了.
在这里重新列出数组`a`中五个指针的值在内存中大致的存放情况：==0100000000000000 0200000000000000 0300000000000000 0400000000000000 0500000000000000==.

对于`*((char *)a + 1)`：数组名`a`在这里退化为指向数组`a`中首元素的指针, 即退化为“指针的指针”. 现在将指针`a`强制转换为字符型指针, 再让`a`迈出1步, 可以标出所得指针指向的内容以及其访问权限：==01**00**000000000000 0200000000000000 0300000000000000 0400000000000000 0500000000000000==. 那么解引用所得指针后, 得到16进制数==00==, 其10进制表示为0, 即原表达式的值为0.

对于`*(int *)(char *)a + 1`：现在将指针`a`强制转换为整型指针, 可以标出所得指针指向的内容以及其访问权限：==**01000000**00000000 0200000000000000 0300000000000000 0400000000000000 0500000000000000==. 那么解引用所得指针后, 得到16进制数==00000001==, 其10进制表示为1. 原表达式等价于：`1 + 1`, 值为2.

对于`*((int *)a + 2)`：现在将指针`a`强制转换为整型指针, 再让`a`迈出2步, 可以标出所得指针指向的内容以及其访问权限：==0100000000000000 **02000000**00000000 0300000000000000 0400000000000000 0500000000000000==. 那么解引用所得指针后, 得到16进制数==00000002==, 其10进制表示为2, 即原表达式的值为2.

对于`*((long long*)a + 3)`：现在将指针`a`强制转换为`long long`类型指针, 再让`a`迈出3步, 可以标出所得指针指向的内容以及其访问权限：==0100000000000000 0200000000000000 0300000000000000 **0400000000000000** 0500000000000000==. 那么解引用所得指针后, 得到16进制数==0000000000000004==, 其10进制表示为4, 即原表达式的值为4.

对于`*((short *)a + 4)`：现在将指针`a`强制转换为`short`类型指针, 再让`a`迈出4步, 可以标出所得指针指向的内容以及其访问权限：==0100000000000000 **0200**000000000000 0300000000000000 0400000000000000 0500000000000000==. 那么解引用所得指针后, 得到16进制数==0002==, 其10进制表示为2, 即原表达式的值为2.

### (3).题目答案

* 输出结果
**0**
**2**
**2**
**4**
**2**

## 12.结构体变小写奇遇记
>计算出`Node`结构体的大小, 并解释以下代码的运行结果.
>```c
>union data {
>      int a;
>      double b;
>      short c;
>};
>typedef struct node {
>     long long a;
>     union data b;
>     void (*change)(struct node *n);
>     char string[0];
>} Node;
>void func(Node *node) {
>     for (size_t i = 0; node->string[i] != '\0'; i++)
>         node->string[i] = tolower(node->string[i]);
>}
>int main() {
>     const char *s = "WELCOME TO XIYOULINUX_GROUP!";
>     Node *P = (Node *)malloc(sizeof(Node) + (strlen(s) + 1) * sizeof(char));
>     strcpy(P->string, s);
>     P->change = func;
>     P->change(P);
>     printf("%s\n", P->string);
>     return 0;
>}
>```
### (1).核心知识
* 结构体的==内存对齐==：
1.**对齐数**：成员元素的大小与编译器默认对齐数相比, ==更小的值==即为成员元素的对齐数.
2.**对齐方式**：第一个成员元素对齐到偏移量为0的地址处；从第二个成员元素开始（包括第二个成员元素）, 对齐到偏移量为各自对齐数的整数倍的地址处.
3.当结构体作为成员元素时, 认为此时对齐数为其所有成员元素中对齐数的最大值.
* 联合体：所有成员元素共用==同一块==内存空间.
* `malloc`函数：用于在程序运行期间, 动态地向操作系统申请一块内存空间. 申请后, `malloc`函数的返回值是一个`void*`类型（无类型指针）.
* `free`函数：用于释放所申请的内存空间.


### (2).题目解析

当编译器默认对齐数为8时.
对于`union data`类型的联合体：
联合体成员|对齐数|偏移量|大小
|:-:|:-:|:-:|:-:
`int a`|4|0|4（字节）
`double b`|8|0|8（字节）
`short c`|2|0|2（字节）



在其所有成员元素中, 对齐数的最大值是8, 而最大成员`double b`的大小是8（字节）, 8正好是8的整数倍, 故该联合体的大小为8（字节）.


对于`struct node`类型的结构体：
结构体成员|对齐数|偏移量|大小
|:-:|:-:|:-:|:-:
`long long a`|8|0|8（字节）
`union data b`|8|8|8（字节）
`void (*change)(struct node* n)`|8|16|8（字节）
`char string[0]`|1|24|0（字节）

由于`struct node`类型的成员元素`char string[0]`大小为0（字节）, 所以由表可得：该类型的大小为24（字节）.

进入主函数后：
先定义了一个字符型指针`s`, 以一个常量字符串`"WELCOME TO XIYOULINUX_GROUP!"`为`s`赋初值, 则`s`会存储这个常量字符串的地址, 也就是首字符`'W'`的地址.

然后用`malloc`函数手动开辟了一片内存, 把返回的无类型指针强制转换为`Node*`类型, 即`struct node*`类型, 让指针`P`来接收. 这里`strlen(s) + 1`的“+1”是把常量字符串最后的隐式`\0`也计数计入, 这样最后开辟的内存中也能够放下这个`\0`.

之后调用`strcpy(P->string, s)`：指针`P`是`struct node*`类型, 所以这样一个结构体指针可以用`->`来直接访问对应结构体的成员. 这里的指针`P`其实对应了一个结构体, 我们记作`JIEGOUTI`.
这里的意思是, 把常量字符串放入刚开辟的内存中预留好的位置.

`P->change = func`把函数`func`的函数名, 作为函数指针放入了结构体`JIEGOUTI`的成员`change`中.

`P->change`得到函数名`func`, 接下来调用`func(P)`.
在函数`func`内部, 借助`for`语句来遍历以`node->string`为地址的字符串, 该字符串即`"WELCOME TO XIYOULINUX_GROUP!"`. 每次遍历利用`tolower`函数使本次遍历到的字符转为小写形式.

`func(P)`调用结束后, 打印输出字符已经全转为小写形式的字符串.
### (3).题目答案
* 输出结果
**welcome to xiyoulinux_group!**

### 题目答案
>Q：你知道**ls**命令的用法与/ . ~这些符号的含义吗？
>A：**ls**：列出目录中的文件和子目录.
>ls -l：以长格式显示, 包含权限、所有者、大小、修改时间等.
>ls -a：显示所有文件, 包括以.开头的隐藏文件.
>ls -h：与-l结合使用, 以人类可读的格式显示文件大小（如KB, MB）.
>/（根目录）：整个文件系统的最顶层.
>.（当前目录）：用户当前所在的目录.
>~（用户主目录）：当前登录用户的家目录.

>Q：你知道Linux中权限rwx的含义吗？
>A：r（read, 读权限, 数字代表4）：对于文件, 允许读取文件内容；对于目录, 允许查看目录下的文件列表.
>w（write, 写权限, 数字代表2）：对于文件, 允许修改或清空文件内容；对于目录, 允许在目录内创建、删除或重命名文件.
>x（execute, 执行权限, 数字代表1）：对于文件, 允许将其作为程序或脚本运行；对于目录, 允许进入该目录以及访问目录内的文件.

>Q：请问你还懂得哪些与**GNU/Linux**相关的知识呢？
>A：Linux 的目录结构是**单根树形结构**, 所有文件和目录都从根目录 / 开始. 它不像 Windows 那样有 C:\、D:\ 多个盘符, 而是把不同分区、设备、甚至远程文件系统都挂载到 / 下面的某个目录里.
