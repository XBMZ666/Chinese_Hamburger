# 第1章 概述

### 1.2.3 计算机的发展阶段
按照采用的**电子器件**划分, 电子计算机的发展经历了四个阶段：
1. 第一代计算机\
主要特征为逻辑器件使用了**电子管**
2. 第二代计算机\
主要特征为逻辑器件使用了**晶体管**
3. 第三代计算机\
主要特征为逻辑器件使用了**半导体中、小规模集成电路**
4. 第四代计算机\
主要特征为逻辑期间使用了**大规模和超大规模集成电路**

### 1.4.1 计算机的应用领域
1. 科学计算\
使用计算机来完成科研、工程领域的复杂数值计算问题, 被称为科学计算, 也可以被称为**数值计算**

# 第2章 体系结构与组织

### 2.5.2 冯诺依曼机的基本组成
计算机由**运算器**、**控制器**、**存储器**、**输入和输出设备**组成
1. 运算器：对数据进行加工处理——主要对二进制数进行算术运算、逻辑运算, 从而实现逻辑判断
2. 控制器：控制计算机各部件的协调工作——从内存中取出指令和执行指令
3. 存储器：计算机的记忆装置——存放原始数据、中间数据、最终结果, 处理程序
4. 输入设备：将数据、程序输入计算机
5. 输出设备：将计算机处理的结果显示或打印出来

### 2.5.4 计算机系统的组成
计算机系统包括**硬件系统**和**软件系统**两大部分
