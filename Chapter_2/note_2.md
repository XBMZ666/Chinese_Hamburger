# 第2章 C语言概述

### 2.2.1 第1遍：快速概要
* C语言的基本模块是函数.

* 在程序中，使用函数也叫作“**调用函数**”.

* 区分括号：花括号`{}`, 圆括号`()`, 方括号`[]`.

* `printf`函数会将`""`外的参数一并嵌入`""`后, 将`""`中的所有内容打印输出在屏幕上. 而占位符的作用是便是确定`""`外的其所对应的参数嵌入`""`后的位置, 需要根据占位符所对应的参数的数据类型、占位符所对应的参数在打印输出后的具体形式来选取来占位符的具体类型.

### 2.2.2 第2遍：程序细节
* `#include <stdio.h>`这行代码是一条预处理指令, 在预处理阶段由预处理器处理, 处理后则将`stdio.h`这个文件中的所有内容拷贝并粘贴到该行代码所在的位置.

* `stdio.h`的文件名含义是“标准输入/输出头文件”, 因此该文件中包含了输入函数和输出函数.

* C程序一定从`main`函数开始执行.

* 函数后的圆括号`()`, 我们可以用来识别函数, 比如`main()`, 看到`main`后面紧跟着圆括号`()`, 我们便可以确定`main`是一个函数（名）.

* 函数由函数头和函数体共同构成. 函数体只能用花括号`{}`来标记, 不得省略, 也不可替换为圆括号`()`或方括号`[]`.
```c
int main()     //函数头
{              //花括号及其所括的内容
               //都可以视为
}              //函数体
```

* `/* */`既可以用于单行注释, 也可以用于多行注释：只要是在`/*`和`*/`之间的内容都会被编译器忽略；C99新增了`//`这种注释, 只可用于单行注释：让处于本行的, 并且所有置于`//`后的内容成为注释.

* 标识符规则：只能由字母、数字、下划线构成, 并且**必须**以字母或下划线开头, 否则就是不合法的标识符. 注意字母区分大小写.

* 关键字：C语言中的特殊词汇, 不可以被用于作为标识符. 关键字的使用不当会被编译器视为语法错误.

* 在声明一个变量时, 编译器会根据这个变量的数据类型, 在计算机的内存中为这个变量预留空间；在为一个声明过的变量赋值时, 值会被存储在之前为变量预留的位置.

* 使用一个变量时, 若未事先声明过该变量, 那么C程序将无法通过编译.

* 当程序运行至调用某函数时, 控制权会暂时转给该函数, 而函数调用结束后, 控制权会转回主函数`main`.

## 2.4 提高程序可读性的技巧
①选择有意义的函数名\
②写注释\
使用以上两种技巧时, 通常二选一, 避免重复啰嗦.

## 2.6 多个函数
把**函数头**单独用于一个语句, 这种情况即为函数声明, 也被称作函数原型. 函数声明会告知编译器在这个源文件中将要使用源文件中本身存在的被声明函数.

### 2.7.2 语义错误
语义错误：意思上的错误. 由于语义错误并未违反C语言的规则, 所以编译器无法检测出语义错误, 只能由我们自己来找出这些错误.
