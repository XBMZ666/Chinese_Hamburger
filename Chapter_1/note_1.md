# 第1章 初识C语言






## 1.1 C语言的起源
* 1972年, *Dennis Ritch*和*Ken Thompson*在开发UNIX操作系统时设计了C语言. 
* C语言是在B语言的基础上设计的, 其主要目标是成为有用的语言.






## 1.2 选择C语言的理由
### 1.2.1 设计特性
* C语言既具备高级语言的理论抽象, 又保留了对硬件的直接控制能力. C语言中有丰富的类型、函数、语句等, 借助C语言也可以操作内存地址. 

### 1.2.2 高效性
* C语言具有微调控制能力（通常是汇编语言才具有的）, 可以根据具体情况微调程序, 以最大化运行速度、高效化对内存的利用.

### 1.2.3 可移植性
* C语言可以跨系统运行：在一种系统编写的C程序稍作修改或不修改, 就能在其他系统运行.

### 1.2.5 面向程序员
* C语言拥有丰富的运算符；C语言灵活、不严格.






## 1.3 C语言的应用范围
小型计算机（UNIX系统） ——> 微型机（个人计算机） ——> 大型计算机（庞然大物）





## 1.4 计算机能做什么
计算机的构成：

①CPU（中央处理单元）：处理程序.

②RAM（随机存取内存）：即我们平时称呼的“**内存**”. 程序运行期间, 存储程序和数据, 供CPU直接读写.

③永久内存存储设备：即我们平时称呼的“**外存**”, 过去一般指机械硬盘, 现在还指固态硬盘. 持久地存储程序和数据, 即使关机, 也不会丢失已存储的程序和数据.






## 1.5 高级计算机语言和编译器
高级语言：供人理解；机器语言：供计算机理解，供CPU使用.






## 1.6 语言标准
ANSI C <C89> / ISO C <C90> ——> C99 ——> C11






## 1.7 使用C语言的七个步骤
C语言是**编译型**语言.

①定义程序的目标：想干啥, 想实现啥?

②设计程序：为了实现目标, 可以做点啥, 做的时候用哪些方法？

③编写代码：写写写……付诸实践, 最终得到若干个源文件.

④编译：这个编译一般包含了“预处理”、“编译”、“汇编”、“链接”这四个阶段, 最终得到可执行文件. 

在Linux环境下, 源代码文件的扩展名是c, 经过预处理后的文件扩展名是i, 再经过编译后的文件扩展名是s, 又经过汇编后的文件扩展名是o. 注意：最后经过链接后的文件没有扩展名, 未命名则默认命名为a.out.

⑤运行程序：得到可执行文件后, 跑一跑看看.

⑥测试和调试程序：找bug.

⑦维护和修改程序：有了新想法, 更新代码, 比如换一种解决问题的方法, 比如变更程序的功能.






## 1.8 编程机制
* 计算机环境：程序运行期间, 以该程序为参照的且被该程序依赖的外部条件. 由计算机硬件、计算机软件、外部服务（数据库、第三方API、云资源）、权限、策略、许可等共同构成.
* C语言具有可移植性, 可以在许多环境中使用.
* 文件名的构成：基本名.扩展名（比如文件名name.c, 其中, name是基本名, c是扩展名）
* 编辑器：用于编写程序, 程序的内容被存储入文本文件. 程序的内容被称为源代码, 这种文本文件被称为源代码文件, 简称源文件. 源文件的扩展名为c, 即后缀为“.c”.

### 1.8.1 目标代码文件、可执行文件和库
* C编程：源代码文件 ——> 可执行文件
* 典型的C实现通过编译、链接这两个步骤来完成“源代码文件 ——> 可执行文件”. 
1. 编译（器）：源代码（文件） ——> 目标代码（文件）
2. 链接（器）：目标代码（文件） ——> 可执行（文件）
* 目标代码文件缺失启动代码、库函数的代码（库代码）, 所以链接器会把我们编写的目标代码、系统的标准启动代码、库函数的代码（库代码）合并成一个文件, 即可执行文件. 注意：链接器只会把要用到的库函数的代码（库代码）提取出来.

### 1.8.3 GNU编译器集合和LLVM项目
* GNU的意思是：“GNU's Not UNIX”. 
* GNU项目的计划：写一个完全自由的操作系统（代码公开, 任何人都能使用和修改）.
* GCC：GNU C Compiler, 即GNU C 编译器；GNU编译器集合：GNU Compiler Collection.

### 1.8.4 Linux系统
* 实际上, Linux是一个**内核**, 所以“Linux系统”可以被称为“以Linux为内核的系统”. 比如：Linux的发行版Ubuntu系统就是一个以Linux为内核的系统.


### 1.8.7 Windows/Linux
不能通过Windows系统访问Linux文件, 但是可以通过Linux系统访问Windows文档.
