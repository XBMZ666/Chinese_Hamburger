# 第7章 分支和跳转

### 7.2.3 多重选择`else if`
编译器的求值原则是能求则求, 不能求的则放在运行阶段由CPU求值.

### 7.2.4 `else`与`if`配对
`else`与离它最近, 且尚未配对的`if`配对.

### 7.3.2 优先级
`&&`的优先级比`||`高.

### 7.3.4 范围
`if(90 <= range <= 100)`存在语义错误, 而编译器无法发现语义错误, 此处需要修改为`if(range >= 90 && range <= 100)`.

### 7.7.1 `switch`语句
关键字`break`可用于循环和`switch`语句中, 而关键字`continue`只能用于循环中.

## 7.8 `goto`语句
最好不要使用`goto`语句！`goto`语句最有用的场景：需要从一组嵌套循环中跳出.
